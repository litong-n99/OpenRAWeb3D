B. 期望结果摘要

  • StartGame 前 → recordingToFile=false
  • StartGame 后 → recordingToFile=true

E3: 二进制输出与回读

  • dispose() 后 → getBuffer() != null
  • 尾部包含 MetaStartMarker=-1

E4: ReplayConnection 属性

  • IsValid=true, TickCount=>=0
  • localClientId = -1

E5: 订单分发

  • Frame 0 → receiveImmediateOrders
  • Frame > 0 → receiveOrders
