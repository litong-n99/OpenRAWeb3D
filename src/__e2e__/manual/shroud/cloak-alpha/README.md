# Shroud — Cloak Alpha Effect Visual Test

**审核状态**: 待审核 (Pending Review)

## 期望结果 (Expected Results)

1. **隐形-拥有者视角**: 隐形单位从拥有者（盟友）视角以 alpha=0.55 半透明渲染。
   - 可量化指标: 左视口（绿色背景）中金色坦克可见但呈半透明状，alpha=0.55（55% 不透明度）
   - 可量化指标: 地面材质/颜色透过坦克可见（透过率约 45%）
   - 可量化指标: 坦克颜色保持金色 `Color3(0.8, 0.7, 0.3)`，仅透明度降低

2. **隐形-敌方视角**: 隐形单位从敌方视角完全不可见。
   - 可量化指标: 右视口（红色背景）中无坦克渲染，仅可见地面
   - 可量化指标: `enemyUnit.isVisible === false`，mesh 被完全禁用
   - 可量化指标: 左右视口对比时差异极为明显（一个能看到半透明坦克，一个完全看不到）

3. **解除隐形-攻击/移动**: 攻击或移动后单位变为完全不透明。
   - 可量化指标: 点击"攻击"后两个视口中的坦克 alpha=1.0，完全不透明
   - 可量化指标: 状态面板显示 "Uncloaked" 和剩余 ticks 倒计时
   - 可量化指标: 敌方视口坦克变为可见，颜色与拥有者视口一致

4. **重新隐形 (CloakDelay)**: 解除隐形后在 CloakDelay ticks 后自动重新隐形。
   - 可量化指标: 默认 CloakDelay=30 ticks，100ms/tick 约 3 秒后恢复隐形
   - 可量化指标: 倒计时归零时状态面板变为 "Cloaked"，敌方坦克消失，拥有者坦克恢复 alpha=0.55
   - 可量化指标: 调节 CloakDelay 滑块可改变恢复时间（如 10 ticks=1秒, 120 ticks=12秒）

## 检验流程

### 1. 准备工作

- 打开测试页面: `http://localhost:5173/test/shroud/cloak-alpha/`
- 确认双视口布局: 左视口"拥有者视角"（绿色调背景）、右视口"敌方视角"（红色调背景）
- 确认环境信息栏显示 **"引擎: WebGL 2.0"**

### 2. 步骤一: 隐形状态验证

- 操作: 页面加载后单位处于隐形状态
- 观察点:
  - 左视口: 金色坦克半透明可见，可以透过坦克看到绿色地面
  - 右视口: 无坦克，仅红色地面可见
- 预期: 状态面板显示 "Cloaked"，拥有者 alpha=0.55，敌方 alpha=0.00

### 3. 步骤二: 解除隐形（攻击）

- 操作: 点击"攻击 (Uncloak)"按钮（或按 A）
- 观察点:
  - 左视口: 坦克立即变为完全不透明，颜色饱满
  - 右视口: 坦克立即出现，完全不透明
  - 状态面板显示 "Uncloaked: 30 ticks" 倒计时
- 预期: 两个视口的坦克外观完全一致（完全不透明、金色）

### 4. 步骤三: 自动重新隐形

- 操作: 等待 CloakDelay 时钟倒计时
- 观察点:
  - 倒计时每 tick 递减
  - 倒计时归零时右视口坦克瞬间消失
  - 左视口坦克恢复半透明状态（alpha=0.55）
- 预期: 重新隐形瞬间完成，无闪烁或过渡异常

### 5. 步骤四: 解除隐形（移动）

- 操作: 点击"移动 (Uncloak)"按钮（或按 M）
- 观察点:
  - 坦克位置向右移动 0.1 单位
  - 同时触发解除隐形（alpha=1.0 可见）
  - 倒计时重新开始
- 预期: 移动和解除隐形同时发生，两个视口保持一致

### 6. 步骤五: CloakDelay 调整

- 操作: 将 CloakDelay 滑块拖到 10 ticks
- 操作: 点击"攻击"解除隐形
- 观察点: 约 1 秒后自动重新隐形（10 ticks x 100ms/tick）
- 操作: 将 CloakDelay 滑块拖到 120 ticks
- 操作: 点击"移动"解除隐形
- 观察点: 约 12 秒后才重新隐形
- 预期: 延迟时间与滑块设置成正比

### 7. 边界/异常测试

- **边界 A - 快速攻击**: 在隐形期间连续点击"攻击"按钮 5 次
  - 预期: remittTime 维持在最大值（取 max(existing, CloakDelay)），倒计时不叠加
- **边界 B - 手动等待**: 点击"等待隐形"按钮强制重置剩余时间为 0
  - 预期: 立即恢复到隐形状态
- **边界 C - 摄像机独立**: 旋转一个视口的摄像机不影响另一个
  - 预期: 两个视口摄像机独立
