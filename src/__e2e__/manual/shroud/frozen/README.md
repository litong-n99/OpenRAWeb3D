## 期望结果 (Expected Results)

1. **迷雾中冻结渲染**: 建筑在 Explored/Fog 区域渲染为半透明灰色调冻结快照。
   - 可量化指标: 冻结建筑 alpha=0.5（50% 不透明度），相比可见建筑的 alpha=1.0 显著降低
   - 可量化指标: 冻结建筑 RGB 色值为灰色 `Color3(0.35, 0.35, 0.35)`（去饱和），相比原始颜色（如橙色 `Color3(0.9, 0.45, 0.1)`）明显灰度化
   - 可量化指标: 冻结建筑无高光（specularColor=black, (0,0,0)）

2. **可见区域实时渲染**: 建筑在 Visible 区域渲染为完全不透明的全彩色。
   - 可量化指标: alpha=1.0，diffuseColor 为建筑原始颜色（A1=橙色, B1=蓝色, C1=绿色, D1=粉色）
   - 可量化指标: 建筑 HP=100% 时颜色饱满，HP<100% 时颜色按比例变暗（health * 颜色值）

3. **状态切换即时**: 从 Fog 切换到 Visible 时冻结快照即刻消失，实时建筑立即出现。
   - 可量化指标: 无双重渲染（live mesh 和 frozen clone 不会同时 visible）
   - 可量化指标: 切换时 FPS 无明显波动（保持在 55-60）

4. **隐藏区域完全不可见**: 建筑在 Hidden 区域完全不可见。
   - 可量化指标: live mesh 和 frozen clone 的 `isVisible` 均为 `false`
   - 可量化指标: 状态面板显示 "invisible"

5. **独立追踪**: 4 个建筑各自独立追踪冻结状态。
   - 可量化指标: 在"部分迷雾"模式下，A1 和 C1（左侧两个）为 Live，B1 和 D1（右侧两个）为 Frozen
   - 可量化指标: 状态面板 4 个条目独立显示各自的 Live/Frozen/Hidden 状态

## 检验流程

### 1. 准备工作

- 打开测试页面: `http://localhost:5173/test/shroud/frozen/`
- 确认环境信息栏显示 **"引擎: WebGL 2.0"**
- 页面加载后 4 个彩色建筑（橙色、蓝色、绿色、粉色）在地形上清晰可见

### 2. 步骤一: 全部可见 vs 全部迷雾

- 操作: 点击"全部可见"按钮（或按 V）
- 观察点: 4 个建筑均为全彩色、不透明立方体
- 预期: 状态面板全部显示 "Live alpha=1.0"

- 操作: 点击"全部迷雾"按钮（或按 F）
- 观察点:
  - 地形覆盖半透明暗灰色滤镜
  - 4 个建筑变为灰色调（去饱和）、透明度约 50%
  - 建筑下方的地形可见但暗灰色
- 预期: 状态面板全部显示 "Frozen alpha=0.5 desat"
- 预期: 冻结建筑的灰色调色彩明显区别于实时建筑的鲜艳颜色

- 操作: 点击"全部可见"回到实时状态
- 观察点: 灰色建筑瞬间变回彩色，**无双重渲染**（不会出现一灰一彩叠在一起的现象）
- 预期: 切换流畅，无闪烁

### 3. 步骤二: 部分迷雾模式

- 操作: 点击"部分迷雾"按钮（或按 P）
- 观察点:
  - 左半区域（Visible）：A1（橙色）和 C1（绿色）为 Live
  - 右半区域（Explored/Fog）：B1（蓝色）和 D1（粉色）为 Frozen（灰色半透明）
  - 中间分界线可见
- 预期: 左右两侧建筑渲染状态明显不同；Live 建筑色彩鲜艳，Frozen 建筑灰色半透明

### 4. 步骤三: 全部隐藏

- 操作: 点击"全部隐藏"按钮（或按 H）
- 观察点:
  - 地形完全被黑色覆盖
  - 所有建筑完全不可见
- 预期: 状态面板全部显示 "Hidden invisible"

### 5. 步骤四: 健康状态变化

- 操作: 点击"全部可见"→ 点击"建筑B1受损"按钮 → 再点击"全部迷雾"
- 观察点:
  - 在全部可见时，B1（右上蓝色建筑）颜色变暗（HP=60% 时颜色约 72% 亮度）
  - 切换到全部迷雾后，B1 的冻结快照为更暗的灰度（健康值影响冻结灰度）
  - 其他建筑不受影响
- 预期: 冻结快照反映健康状态变化；受损建筑的冻结版比满血建筑的冻结版更暗

- 操作: 点击"全部修复"按钮
- 观察点: B1 恢复满血状态
- 预期: 恢复到期望 #1 和 #2 的状态

### 6. 边界/异常测试

- **边界 A - 快速切换**: 连续快速点击 "V → F → H → V" 循环 5 次
  - 预期: 无 WebGL 崩溃，无运行时错误，建筑不丢失
- **边界 B - 极端缩放**: 将摄像机缩放到距离 2 以下
  - 预期: 冻结建筑灰色调和 live 建筑色彩的差异依然清晰可辨
