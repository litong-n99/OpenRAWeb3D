期望结果 (Expected Results)

  • 迷雾中冻结: 建筑在 Explored/Fog 区域渲染为 alpha=0.5 且灰色调 (desaturated ~60%饱和度)
  • 可见区域实时: 建筑在 Visible 区域渲染为 alpha=1.0 全色，橙色/蓝色原始颜色
  • 迷雾清除: 从 Fog 切换回 Visible 时冻结快照 立即替换 为实时建筑 (无双重渲染)
  • 隐藏区域不可见: 建筑在 Hidden 区域完全 不可见 (alpha=0)，包括冻结快照
  • 独立追踪: 4个建筑各自独立跟踪 冻结状态，互不干扰
  • 状态变化保留: 冻结快照保留建筑 形态，但颜色为灰色调、透明度50%
