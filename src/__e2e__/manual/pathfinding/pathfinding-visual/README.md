# Pathfinding — HPA* Hierarchical Pathfinding Visual Test

**OpenRA 对照**: `OpenRA.Mods.Common/Pathfinder/HierarchicalPathFinder.cs`, `PathSearch.cs`  
**测试重点**: A* 基础路径查找、HPA* 层次抽象图、Domain 连通域、搜索空间对比  
**坐标系约定**: 网格在 XZ 平面上，Y=0 为地面层，起始障碍物密度 0%

## 重要说明 (Important Note)

**此测试页面实现独立的 A* 和 HPA* 可视化算法，用于直观验证路径查找的行为。**
生产代码 (`HierarchicalPathFinder.ts`, `PathSearch.ts`) 已由 **190 个单元测试** 充分覆盖。
此页面中的算法实现与生产代码独立，仅用于可视化演示目的。生产代码的正确性由单元测试保证。

## 期望结果 (Expected Results)

### 1. A* 基础路径查找

起点(绿色标记, #44CC44)到终点(红色标记, #EE3333)应找到最短路径，路径以黄色球体 (#FFCC00) 标记。

- **可量化标准**: 无障碍物时路径长度应等于**曼哈顿距离** (|dx| + |dy|)，起点(2,14)到终点(27,14)路径长度为 **25** cells
- **可量化标准**: 添加障碍物后路径应**绕行**，无穿越不可行走格子 (灰色方块, #404040)
- **可量化标准**: A* 搜索空间 (青色高亮, rgba(0,200,255,0.5)) 覆盖从起点到终点的合理搜索区域，不应在终点反方向大量扩展

### 2. HPA* 层次路径查找

蓝色框 (rgba(50,100,200,0.7)) 标出 10x10 抽象网格边界，白色球体标记抽象节点，白色半透明线连接抽象图边。

- **可量化标准**: 对于 30x30 网格，应产生 **9 个** 抽象网格 (3x3 cluster grid)
- **可量化标准**: 无障碍物时每个 10x10 cluster 应有 **1 个** 抽象节点，共 9 个; 白色抽象节点球体清晰可见
- **可量化标准**: HPA* 搜索节点数应**少于 A*** (减少约 30-70%)，统计面板 "搜索节点减少" 显示为正百分比

### 3. Domain 连通域可视化

不同连通域用不同颜色渲染，有障碍物隔离的区域显示为不同颜色。

- **可量化标准**: 无障碍物时整个地图为 **1 个** 连通域 (单一颜色)
- **可量化标准**: 放置一堵全高墙后，应有至少 **2 个** 连通域 (不同颜色)
- **可量化标准**: 相邻且无阻隔的格子应**同色**，被障碍物阻隔的格子应**异色**

### 4. 性能对比

左侧面板实时显示 A* 和 HPA* 的统计数据。

- **可量化标准**: 30x30 网格 A* 路径查找耗时 < **5ms**
- **可量化标准**: HPA* 路径查找耗时 < **3ms**
- **可量化标准**: FPS 稳定在 **55-60** (包含纹理更新和 3D 渲染开销)

### 5. 交互响应

- **可量化标准**: 拖动起点/终点滑块后点击"重新计算"，路径更新延迟 < **100ms**
- **可量化标准**: Ctrl+Click 切换障碍物后，结果即时更新（纹理刷新 + 路径重算 < 200ms）
- **可量化标准**: 按 `1`-`5` 键切换可视化模式，切换延迟 < 100ms

## 检验流程

### 1. 准备工作

- 打开测试页面: `http://localhost:5173/test/pathfinding/pathfinding-visual/`
- 确认环境信息栏显示 **"WebGL 2.0"** 引擎
- 设置屏幕分辨率为 1920x1080 (1x 缩放)
- 确认页面加载后网格可见，起点(绿色)和终点(红色)已显示

### 2. 步骤一: A* 基础路径查找验证

- 操作: 确认可视化模式为 "A* 搜索空间 (青色)" 按钮高亮
- 观察点:
  - 起点到终点有一条**黄色球体路径**
  - 统计面板显示路径长度约 25 cells
  - 搜索节点数显示在 "A* 搜索结果" 区域
  - 青色半透明高亮覆盖搜索区域
- 预期: ✅ 最短路径, 绕行无障碍 (当前无障碍), 搜索节点 > 路径长度

### 3. 步骤二: 障碍物绕行验证

- 操作: 点击 "随机障碍 (30%)" 按钮
- 观察点:
  - 灰色方块出现在网格上
  - 黄色路径绕行灰色方块
  - 路径不穿越任何灰色方块
  - 搜索节点数明显增加
- 操作: Ctrl+Click 在一个狭窄通道上添加/移除障碍物，观察路径更新
- 预期: ✅ 路径动态更新, 绕行正确

### 4. 步骤三: HPA* 层次结构验证

- 操作: 点击 "HPA* 层次结构" 按钮 (或按 `5`)
- 观察点:
  - 蓝色线条标出 10x10 抽象网格
  - 白色球体标记每个 cluster 的抽象节点
  - 白色半透明线连接相邻 cluster 的抽象节点
- 切换回 "HPA* 搜索空间" 模式观察紫色高亮
- 预期: ✅ 抽象网格 3x3 = 9 个, 抽象节点可见, 边线连接正确

### 5. 步骤四: Domain 可视化验证

- 操作: 先点击 "清除障碍物"，观察 domain
- 操作: 点击 "Domain 连通域" 按钮 (或按 `4`)
- 观察点: 全图应为一种颜色 (1 个域)
- 操作: 点击 "随机障碍 (30%)"
- 观察点: 应按连通性分割为多种颜色
- 操作: Ctrl+Click 制造一堵完整的隔离墙
- 观察点: 墙两侧应为不同颜色
- 预期: ✅ 连通域划分正确, 同域同色, 异域异色

### 6. 步骤五: 性能对比验证

- 操作: 点击 "两者对比" 按钮 (或按 `3`)
- 观察点:
  - 青色区域 (A*) 和紫色区域 (HPA*) 同时显示
  - 统计面板中 HPA* 搜索节点数 < A* 搜索节点数
  - "搜索节点减少" 显示正百分比
- 预期: ✅ HPA* 搜索节点少于 A*, A* 耗时 < 5ms, HPA* 耗时 < 3ms

### 7. 边界/异常测试

- **边界 A - 不可达目标**: 用障碍物完全包围终点
  - 预期: ✅ 统计面板路径长度显示 0, 搜索覆盖可达区域后停止

- **边界 B - 快速切换**: 快速连续按 `1` `2` `3` `4` `5`
  - 预期: ✅ 无崩溃, 无渲染残留, FPS 不持续下降

- **边界 C - 极端缩放**: 滚轮缩放至最近和最远
  - 预期: ✅ 近距离可见网格纹理细节, 远距离可见整体路径轮廓

- **边界 D - 网格边界**: 将起点设在 (0,0)，终点设在 (29,29)
  - 预期: ✅ 路径沿对角线方向，不越界
