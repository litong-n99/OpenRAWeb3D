B. 期望结果 (Expected)

ID: pathfinding/pathfinding-visual

1. A* 基础路径查找

  • 起点(绿色)到终点(红色)应找到最短路径
  • 路径绕行障碍物, 无穿越不可行走格子
  • 搜索节点数以青色半透明高亮显示

2. HPA* 层次路径查找

  • 蓝色框标出10x10抽象网格
  • 白色球体标记抽象节点, 白色线连接抽象边
  • HPA* 搜索节点数应少于 A* (约减少 30-70%)

3. Domain 可视化

  • 不同连通域用不同颜色渲染
  • 有障碍物隔离的区域应显示为不同颜色的域
  • 相邻且连通的区域应同色

4. 性能对比

  • A* 搜索节点数普遍> HPA* 搜索节点数
  • 30x30 网格 A* 路径查找耗时应 < 5ms
  • HPA* 路径查找耗时应 < 3ms
