## 测试目标

本测试页面验证 Mobile 系统的单位转向机制。OpenRA 使用 `WAngle.tickFacing()` 实现逐步旋转：每个 tick 最多旋转 `turnSpeed` 个 WAngle 单位（默认 32，约 11.25°/tick），不会瞬间跳变到目标方向。关键验证点包括：转向动画不跳过、转速上限、最终朝向精度、转向帧数与角度成正比、小角度跳过动画。

## 坐标系约定

- **WAngle 编码**: 0-1024 表示 0°-360°（256 = 90°）
- **方向基准**: WAngle 0 = 北 (North)，逆时针递增
  - 0 = 北 (N, +Z in Babylon)
  - 256 = 东 (E, +X)
  - 512 = 南 (S, -Z)
  - 768 = 西 (W, -X)
- **转换公式**: `度数 = WAngle * 360 / 1024 = WAngle * 0.3515625`
- **5°阈值**: `5° × 1024 / 360 ≈ 14.2 WAngle units → 取整为 14`

## B. 期望结果（可量化验收标准）

### 期望 1: 转向动画播放 — 非瞬间跳变

**操作**: 设置 TurnSpeed = 32 WA/tick，Tick 间隔 = 40ms，点击「南 (512)」（从北 0 转 180°）。

**观察点**:
- 单位应**逐步旋转**，而非瞬间跳到南方向
- 转向环（橙色圆环）在旋转期间发光
- 状态栏显示「转向中...」并显示 tick 计数递增
- 转向帧指示器显示旋转符号（◐◓◑◒ 循环）

**量化标准**:

| 检查项 | 预期行为 | 容差 |
|--------|---------|------|
| 完成 180° 转向所需 tick 数 | 512/32 = **16 ticks** | ±1 tick |
| 完成时间 (40ms/tick) | 16 × 40 = **~640ms** | ±80ms |
| 每 tick 旋转量 | ≤ 32 WA (11.25°) | 0 WA |
| 跳变检测 | 无瞬间角度跳变（肉眼观察） | 0 次跳变 |
| 转向环颜色 | 旋转中为**橙色** (#E6991A)，完成后恢复**灰蓝色** (#4D4D66) | 明显可辨 |

### 期望 2: TurnSpeed 上限约束

**操作**: 设置 TurnSpeed = 16 WA/tick，点击「东 (256)」（从北 0 转 90°）。

**观察点**:
- 每 tick 的 facing 变化**不超过 16 WA units**（约 5.625°）
- 状态栏「角度差」每 tick 递减 16 或更少
- 不会出现一次性跳变超过设定值

**量化标准**:

| 检查项 | 预期行为 |
|--------|---------|
| 每 tick 最大变化 | ≤ 16 WA |
| 90° 转向所需 tick 数 | 256/16 = **16 ticks** |
| TurnSpeed=8 时 90° 转向 | 256/8 = **32 ticks** |
| TurnSpeed=128 时 90° 转向 | 256/128 = **2 ticks** |

### 期望 3: 最终朝向 = 目标方向（±1° 精度）

**操作**: 依次发送方向指令到 8 个方向（0, 128, 256, 384, 512, 640, 768, 896），每次等待转向完成。

**观察点**:
- 每次转向完成后，「当前 Facing」应**精确等于**「目标 Facing」
- 角度差显示为 0 WA / 0.0°
- 状态栏显示「已对齐」

**量化标准**:

| 目标方向 (WA) | 对应角度 | 期望最终 facing | 容差 |
|--------------|---------|----------------|------|
| 0 (北) | 0.0° | 0 | ±3 WA (±1°) |
| 128 (东北) | 45.0° | 128 | ±3 WA |
| 256 (东) | 90.0° | 256 | ±3 WA |
| 384 (东南) | 135.0° | 384 | ±3 WA |
| 512 (南) | 180.0° | 512 | ±3 WA |
| 640 (西南) | 225.0° | 640 | ±3 WA |
| 768 (西) | 270.0° | 768 | ±3 WA |
| 896 (西北) | 315.0° | 896 | ±3 WA |

### 期望 4: 转向帧数与角度成正比

**操作**: 固定 TurnSpeed = 32，依次执行不同角度的转向。

**观察点**:
- 转向 tick 数 = ⌈角度差 / TurnSpeed⌉
- 大角度转向需要更多 tick，小角度需要更少

**量化标准**:

| 角度差 (WA) | 角度 (°) | TurnSpeed=32 预期 tick | TurnSpeed=16 预期 tick |
|------------|---------|----------------------|----------------------|
| 512 | 180° | 16 | 32 |
| 256 | 90° | 8 | 16 |
| 128 | 45° | 4 | 8 |
| 64 | 22.5° | 2 | 4 |
| 32 | 11.25° | 1 | 2 |

### 期望 5: ≤5° 角度差（≤14 WA）不触发转向动画

**操作**: 使用「小角度阈值测试」面板，设置角度差 ≤14 WA（约 5°），点击「执行小角度转向」。

**观察点**:
- 单位**瞬间**完成方向变更（无逐步旋转）
- 转向环**不变色**（保持灰蓝色，不变成橙色）
- 状态栏显示「小角度(瞬间完成)」
- 「动画触发?」显示「否」
- tick 计数保持为 0

**量化标准**:

| 小角度差 (WA) | 预期行为 |
|-------------|---------|
| ≤14 (~5°) | 瞬间跳变，无动画 |
| 16-20 (~5.6°-7°) | 触发 1 个 tick 的转向 |
| >20 | 正常转向动画 |

### 期望 6: WAngle 坐标系正确性

**操作**: 观察 3D 场景中单位箭头的朝向。

**观察点**:
- WAngle 0 (北): 单位箭头指向屏幕上方（+Z 轴，North）
- WAngle 256 (东): 单位箭头指向屏幕右侧（+X 轴，East）
- WAngle 512 (南): 单位箭头指向屏幕下方（-Z 轴，South）
- WAngle 768 (西): 单位箭头指向屏幕左侧（-X 轴，West）
- 地面指南针 N(0)/E(256)/S(512)/W(768) 标记应与单位朝向一致

**量化标准**:
- 每个主方向偏差 ≤ 2°（肉眼可辨对齐）
- 逆时针转动（从北→东→南→西 对应 WAngle 递增）

### 边界/异常测试

1. **极限转速 TurnSpeed=512**: 设置 TurnSpeed=512（180°/tick），180° 转向应在 1 tick 内完成
2. **最小转速 TurnSpeed=4**: 设置 TurnSpeed=4（~1.4°/tick），90° 转向需要 64 ticks (~2.56 秒)
3. **连续快速转向**: 在转向未完成时点击新方向 → 应中断当前转向，开始新转向
4. **跨 0° 边界**: 从 896 (西北, 315°) 转向 128 (东北, 45°) → 应走最短路径（逆时针 256 WA 而非顺时针 768 WA）
5. **速度缩放**: 将 Tick 间隔调为 10ms → 转向加速 4x；调为 200ms → 转向减速 5x

## 技术说明

### tickFacing 算法

```typescript
// WAngle.tickFacing(current, desired, step):
const diff = (desired - current) % 1024
if (diff === 0) return current
const absDiff = diff > 512 ? 1024 - diff : diff  // 最短路径
const sign = diff <= 512 ? 1 : -1                // 旋转方向
const move = Math.min(absDiff, step)              // 不超过 step
return new WAngle(current + sign * move)
```

该算法保证每次 tick 旋转量不超过 step，并总是走最短角度路径（跨 0° 边界时正确处理）。

### 与 Mobile.ts 的关系

本测试页面直接导入 `WAngle.tickFacing()` 并独立运行，不依赖完整的 Mobile trait。转向逻辑与 Mobile.UpdateMovement() 中 MovementType.Turn 设置逻辑一致：

- `Mobile.facing` 更新时，`updateMovement()` 检测 `oldFacing !== facing`
- 若不同，设置 `MovementType |= MovementType.Turn`
- Turn 动画由 `RenderSprites` trait 根据 `MovementType.Turn` 标志触发
