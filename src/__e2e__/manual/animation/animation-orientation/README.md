# Animation - 朝向切换动画验证

> **人工验收测试页**
> 模块: Animation (facingFunc, WAngle)
> 测试ID: `animation/animation-orientation`
> OpenRA 对照: `Animation.ts` — facingFunc, WAngle (0-1023), getSprite(frame, facing)
> 创建日期: 2026-06-06

---

## 测试目标

本测试页面验证 Animation 系统中的朝向切换机制。OpenRA 使用 WAngle（0-1023 表示 0-360 度）来表达单位的面对方向。`facingFunc` 回调在每次 `getSprite()` 时查询当前朝向以选择正确的精灵帧。朝向切换的正确性直接影响 RTS 游戏中单位移动方向的视觉反馈。

---

## B. 期望结果（可量化验收标准）

### 期望 1: WAngle 到角度的映射正确

**操作**: 拖动「朝向角度」滑块从 0 到 1023。

**观察点**:
- WAngle 0 → 中心箭头指向正上方（北，0°）
- WAngle 256 → 中心箭头指向正右方（东，90°）
- WAngle 512 → 中心箭头指向正下方（南，180°）
- WAngle 768 → 中心箭头指向正左方（西，270°）
- WAngle 1023 → 中心箭头指向接近北（359.6°）

**量化标准**:
| WAngle | 预期箭头指向 | 角度容差 |
|--------|------------|---------|
| 0 | 正上 (北, 0°) | ±3° |
| 256 | 正右 (东, 90°) | ±3° |
| 512 | 正下 (南, 180°) | ±3° |
| 768 | 正左 (西, 270°) | ±3° |

### 期望 2: 方向指示器高亮正确

**操作**: 拖动滑块经过所有 8 个朝向分区。

**观察点**:
- 周围 8 个方向指示器（N/NE/E/SE/S/SW/W/NW）中，**当前朝向对应的指示器应明显放大**
- 非活跃指示器保持较小尺寸（缩小到约 40% 透明度）
- 活跃指示器切换**立即**响应滑块变化（<50ms）

**量化标准**:
| 检查项 | 预期行为 |
|--------|---------|
| 活跃指示器缩放 | ≥ 1.3x（肉眼可见明显放大） |
| 非活跃指示器透明度 | ≤ 50%（明显变暗） |
| 边界切换 | WAngle 63→64 时高亮从 N 切换到 NE |

### 期望 3: 指针罗盘实时同步

**操作**: 观察右下角罗盘指示器。

**观察点**:
- 罗盘指针角度与滑块 WAngle 对应角度一致
- N/S/E/W 标签正确标注

### 期望 4: 自动旋转平滑

**操作**: 勾选「自动旋转」，设置旋转速度为 1x。

**观察点**:
- 箭头平滑旋转（无跳变）
- 约 512 秒完成一个完整旋转（1x 速度 = 2 WAngle/帧，60fps = 120/s，1024/120 ≈ 8.5s）
- 方向指示器高亮平滑切换

### 期望 5: FPS 稳定性

**操作**: 自动旋转模式运行 10 秒。

**量化标准**:
- FPS ≥ 55（60Hz 显示器）

## 检验流程

### 准备工作

1. 打开测试页面：`http://localhost:5173/test/animation/animation-orientation/`
2. 确认环境信息栏显示 WebGL 2.0
3. 中央显示大箭头 + 周围 8 个方向指示器 + 右下角罗盘

### 步骤一：基础方向映射验证

1. 点击「面北」→ 中心箭头指向正上
2. 点击「面东」→ 中心箭头指向正右
3. 点击「面南」→ 中心箭头指向正下
4. 点击「面西」→ 中心箭头指向正左
5. 确认每次点击后方向指示器和罗盘同步更新

**预期**: 符合期望 1 和 3 → 继续

### 步骤二：连续朝向扫描

1. 缓慢拖动「朝向角度」滑块从 0 到 1023
2. 观察中心箭头平滑旋转 360°
3. 观察方向指示器高亮依次经过 N→NE→E→SE→S→SW→W→NW→N
4. 确认每个分区边界切换正确（期望 2）

### 步骤三：自动旋转验证

1. 勾选「自动旋转」
2. 设置旋转速度为 1x
3. 观察箭头连续平滑旋转
4. 等待至少 10 秒确认旋转持续无卡顿

**预期**: 符合期望 4 → 继续

### 步骤四：快速旋转

1. 旋转速度设为 10x
2. 箭头应快速旋转但无撕裂
3. 恢复 1x

### 步骤五：随机朝向

1. 连续点击「随机朝向」5 次
2. 每次点击箭头应瞬间跳转到新方向
3. 方向指示器应立即响应

### 边界/异常测试

1. WAngle 0→1023 边界：箭头从 359.6° 平滑过渡到 0°
2. 极快连续点击按钮 → 无崩溃
