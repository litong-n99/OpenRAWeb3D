## 测试目标

本测试页面验证目标线（Target Line）渲染系统的视觉行为：
1. Move 活动的目标线：从单位到目标格子的蓝色虚线
2. AttackMove 活动的目标线：从单位到目标格子的红色虚线
3. 多路径点（waypoint）的线段连接与节点标记
4. 目标线颜色与活动类型的正确对应
5. 目标线随单位移动的动态更新（实时缩短）
6. 到达目标后的淡出消失

---

## B. 期望结果（可量化验收标准）

### 期望 1: 目标线颜色与活动类型对应

**操作**: 分别选择 Unit A（Move）和 Unit B（AttackMove），观察目标线颜色。

**量化标准**:
- Move 活动目标线颜色为 **蓝色 (#3399F2)**，RGB 值 (51, 153, 242)
- AttackMove 活动目标线颜色为 **红色 (#E94560)**，RGB 值 (233, 69, 96)
- 颜色切换即时生效：点击「Move」/「AttackMove」按钮后 **100ms 内**颜色变化
- 颜色选择器可实时修改颜色，修改后目标线颜色 **即时更新**
- **注**: 以上颜色为本测试页约定的视觉区分色，OpenRA 实际目标线颜色由 MobileInfo.TargetLineColor / mod YAML 配置决定

**失败判定**: 颜色与活动类型不匹配或切换延迟 > 200ms → **MAJOR**

### 期望 2: 虚线样式规范

**操作**: 放大观察任意目标线的样式细节。

**量化标准**:
- 目标线为 **虚线**（dash pattern: 8px on / 4px off）
- 线宽 **3px**（在 3D 场景中对应约 0.06 世界单位）
- 线段从 **单位中心**（Y=0.3）出发
- 线段指向 **目标格中心**（Y=0.05）
- 线段在地面之上悬浮，**不穿透地面**

**失败判定**: 实线而非虚线，或线段穿透地面 → **MINOR**

### 期望 3: 路径点节点标记

**操作**: Shift+点击添加多个路径点，观察标记和连线。

**量化标准**:
- 路径点显示为 **黄色八面体**标记，大小 **0.4 世界单位**
- 八面体高度 **0.3**（Y 轴），悬浮于地面之上
- 多路径点时，线段依次连接：单位 → 路径点1 → 路径点2 → ... → 目标
- 每个路径点之间的线段均为虚线，样式与主目标线一致
- 路径点数量在状态栏实时显示

**失败判定**: 路径点标记不可见或连线断裂 → **MAJOR**

### 期望 4: 动态更新与淡出

**操作**: 设置一个目标，观察单位移动过程中目标线的变化。

**量化标准**:
- 单位移动时，目标线 **实时缩短**（起点跟随单位位置）
- 相邻帧之间目标线长度变化连续，**无跳变**
- 单位到达目标后，目标线在 **500ms 内淡出消失**（alpha 从 1.0 渐变到 0.0）
- 目标标记（红色球体）随目标线一同淡出消失

**失败判定**: 目标线不随单位移动更新或到达后不消失 → **BLOCKER**

### 期望 5: 多单位独立目标线

**操作**: 分别给 Unit A 和 Unit B 设置不同目标。

**量化标准**:
- Unit A 和 Unit B 各自显示独立的目标线
- 两条目标线颜色不同（蓝色 vs 红色），**无混淆**
- 选中单位时显示黄色选择环，未选中单位的选择环隐藏
- 切换选中单位（A/B 按钮或 A/B 键）后选择环 **即时切换**

**失败判定**: 多单位目标线重叠或选择环不切换 → **MAJOR**

## 检验流程

### 准备工作

1. 打开测试页面：`http://localhost:5173/test/activities/target-lines/`
2. 确认环境信息栏显示 WebGL 2.0
3. 确认 FPS 显示在 50-60 范围
4. 确认场景中有两个单位（Unit A: 绿色，Unit B: 紫色）和各自的目标线

### 步骤一：颜色验证

1. 确认 Unit A 显示蓝色目标线（默认 Move 活动）
2. 点击「AttackMove」按钮，确认目标线变为红色
3. 点击「Move」按钮，确认目标线恢复蓝色
4. 使用颜色选择器修改颜色，确认目标线即时更新

**预期**: ✅ 符合期望 1

### 步骤二：虚线样式

1. 放大摄像机（滚轮向上）观察目标线细节
2. 确认虚线 pattern（dash-gap-dash）
3. 确认线段从单位中心出发，指向目标格中心
4. 确认线段悬浮于地面之上

**预期**: ✅ 符合期望 2

### 步骤三：路径点

1. 选中 Unit A
2. Shift+点击地面添加 3 个路径点
3. 确认黄色菱形标记出现在每个路径点位置
4. 确认虚线依次连接：单位 → 路径点1 → 路径点2 → 路径点3 → 目标
5. 点击「清除路径点」，确认所有路径点标记和连线消失

**预期**: ✅ 符合期望 3

### 步骤四：动态更新

1. 设置一个较远的目标（如对角线远端）
2. 观察单位移动过程中目标线实时缩短
3. 确认单位到达目标后目标线淡出消失
4. 确认目标标记（红色球体）同步消失

**预期**: ✅ 符合期望 4

### 步骤五：多单位

1. 选中 Unit A，设置一个目标
2. 选中 Unit B，设置另一个目标
3. 确认两条独立的目标线同时显示
4. 按 A 键选中 Unit A，确认黄色选择环在 Unit A
5. 按 B 键选中 Unit B，确认黄色选择环切换到 Unit B

**预期**: ✅ 符合期望 5

### 边界/异常测试

1. **快速切换活动类型**：连续点击 Move/AttackMove 10 次 → 颜色切换无延迟
2. **大量路径点**：添加 10+ 路径点 → 所有标记和连线正确显示
3. **目标在障碍物上**：点击灰色方块 → 不设置目标，无异常
4. **切换目标线显示**：按 L 键切换显示/隐藏 → 目标线即时显示/隐藏
5. **切换路径点显示**：按 W 键切换显示/隐藏 → 路径点即时显示/隐藏
