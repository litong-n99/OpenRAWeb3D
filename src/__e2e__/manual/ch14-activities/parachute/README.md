## 期望结果 (Expected Results)

1. **下落速度**:
   - 每 tick 下降 `fallRate` WDist (由 ParachutableInfo 配置)。
   - 可量化指标: 慢速 = `64 WDist/tick`，正常 = `128 WDist/tick`，快速 = `256 WDist/tick`。
   - 可量化指标: 从 5120 WDist 高度，正常速率下降需要 `5120 / 128 = 40 ticks`。
   - 可量化指标: 高度显示每 tick 减少 `fallRate`。

2. **着陆**:
   - 到达地面高度 (Z = 0 WDist) 时停止下降。
   - 可量化指标: 着陆后高度 = `0 WDist`。
   - 可量化指标: 水平位置 (X, Y) 保持不变。
   - 可量化指标: 着陆时位置 snapped 到地面水平。

3. **着陆通知**:
   - 着陆时触发 `INotifyParachute.onLanded()` 通知。
   - 可量化指标: 控制台输出 `"[Parachute] onLanded notification triggered"`。
   - 可量化指标: 着陆时出现尘土效果 (棕色半透明球体，持续 30 ticks)。

4. **非中断**:
   - 降落伞活动不可中断 (`isInterruptible = false`)。
   - 可量化指标: 下降过程中点击 "重置" 才能中断，否则继续下降。

5. **视觉表现**:
   - 可量化指标: 白色降落伞伞盖 (直径 1.5 世界单位)。
   - 可量化指标: 棕色单位主体 (0.5 x 0.6 x 0.5 世界单位)。
   - 可量化指标: 下降时降落伞轻微摆动 (正弦波 sway，幅度 0.05 rad)。
   - 可量化指标: 着陆后降落伞消失 (isVisible = false)。

## 检验流程

### 1. 准备工作

- 打开测试页面: `http://localhost:5173/test/activities/parachute/`
- 确认环境信息栏显示 "引擎: WebGL 2.0"
- 设置屏幕分辨率为 1920×1080 (1x 缩放)
- 确认页面显示: 绿色地面、绿色着陆区标记、白色降落伞+棕色单位

### 2. 步骤一: 正常速率下降

- 操作: 选择下落速率为 "正常 (128 WDist/tick)"
- 操作: 选择起始高度为 "中 (5120 WDist)"
- 操作: 点击 "投放单位" 按钮
- 观察点:
  - 单位出现在 5120 WDist 高度
  - 每 tick 高度减少 128 WDist
  - 降落伞轻微摆动
  - 白色下降轨迹线
  - 40 ticks 后到达地面
  - 着陆时出现尘土效果
  - 控制台输出 "[Parachute] onLanded notification triggered"
  - 着陆后降落伞消失
  - 状态变为 "已着陆"
- 预期: ✅ 40 ticks 后精确着陆，触发通知，尘土效果

### 3. 步骤二: 慢速下降

- 操作: 点击 "重置"
- 操作: 选择下落速率为 "慢速 (64 WDist/tick)"
- 操作: 选择起始高度为 "高 (10240 WDist)"
- 操作: 点击 "投放单位"
- 观察点:
  - 高度从 10240 WDist 开始
  - 每 tick 减少 64 WDist
  - 需要约 160 ticks 到达地面
  - 降落伞摆动更慢
- 预期: ✅ 慢速下降，约 160 ticks 着陆

### 4. 步骤三: 快速下降

- 操作: 点击 "重置"
- 操作: 选择下落速率为 "快速 (256 WDist/tick)"
- 操作: 选择起始高度为 "低 (2560 WDist)"
- 操作: 点击 "投放单位"
- 观察点:
  - 高度从 2560 WDist 开始
  - 每 tick 减少 256 WDist
  - 约 10 ticks 到达地面
  - 快速着陆
- 预期: ✅ 快速下降，约 10 ticks 着陆

### 5. 步骤四: 改变投放位置

- 操作: 点击画布上的新位置 (绿色着陆区标记移动)
- 操作: 点击 "投放单位"
- 观察点:
  - 单位在新位置上方出现
  - 垂直下降，水平位置不变
  - 着陆点与投放点水平位置一致
- 预期: ✅ 水平位置不变，垂直下降

### 6. 步骤五: 非中断测试

- 操作: 点击 "投放单位"
- 操作: 下降过程中尝试点击 "投放单位" (不应影响当前下降)
- 观察点:
  - 当前单位继续下降不受影响
  - 新点击不会生成新单位
  - 只有 "重置" 可以中断
- 预期: ✅ 下降过程不可中断，除非重置

### 7. 边界/异常测试

- **边界 A - 从地面高度投放**: 选择起始高度 "低 (2560 WDist)" 但先重置使单位在地面上

  - 预期: ✅ 所有组合都能正确着陆
