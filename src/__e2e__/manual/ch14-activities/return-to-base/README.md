## 期望结果 (Expected Results)

1. **寻找最近可用基地 (ReturnToBase)**:
   - 飞机找到最近的绿色可用基地。
   - 可量化指标: 绿色基地 = `available=true`，灰色基地 = `available=false`。
   - 可量化指标: 目标线颜色 = `#00FF00` (绿色)，连接飞机与目标基地。
   - 可量化指标: 到达基地距离 `< 500 WDist` 时开始着陆。

2. **无可用基地时的行为**:
   - 悬停飞机 (CanHover): 在最近的基地附近盘旋等待。
   - 非悬停飞机: 执行 FlyIdle，盘旋等待 `75 ticks`。
   - 可量化指标: 盘旋半径约 `idleSpeed * 25 / turnSpeed` WDist。
   - 可量化指标: 无基地时目标线消失。

3. **着陆补给**:
   - VTOL: 水平对准后垂直降落。
   - 非VTOL: 边飞边降，逐渐接近地面。
   - 可量化指标: 着陆后停留 `50 ticks` 进行补给。
   - 可量化指标: 补给完成后飞机回到巡航高度。

4. **FlyIdle 盘旋**:
   - 非悬停飞机以 `idleSpeed` (40 WDist/tick) 做圆形盘旋。
   - 可量化指标: 每 tick 转向 `256 WAngle` (90°)。
   - 可量化指标: 盘旋 `75 ticks` 后停止。
   - 可量化指标: 飞行轨迹为圆形或近似圆形。

5. **基地状态切换**:
   - 点击 "模拟无基地" 后所有基地变为灰色 (不可用)。
   - 可量化指标: 基地颜色从绿色变为灰色。
   - 可量化指标: 返航飞机改变行为为盘旋/等待。

## 检验流程

### 1. 准备工作

- 打开测试页面: `http://localhost:5173/test/activities/return-to-base/`
- 确认环境信息栏显示 "引擎: WebGL 2.0"
- 设置屏幕分辨率为 1920×1080 (1x 缩放)
- 确认页面显示: 3 个基地 (2 绿色可用 + 1 灰色不可用)，灰色飞机

### 2. 步骤一: 返航到最近可用基地

- 操作: 选择飞机类型为 "VTOL (垂直起降)"
- 操作: 点击 "返航 (ReturnToBase)" 按钮
- 观察点:
  - 飞机飞向最近的绿色基地 (基地 1 或 2)
  - 绿色目标线连接飞机与目标基地
  - 状态栏显示 "returning" 和目标基地信息
  - 距离显示逐步减小
  - 到达基地后状态变为 "landing"
  - VTOL 水平对准后垂直降落
  - 着陆后状态变为 "resupplying"
  - 50 ticks 后补给完成，飞机回到巡航高度
  - 状态变为 "idle"
- 预期: ✅ 找到最近可用基地，绿色目标线，成功着陆补给

### 3. 步骤二: 无可用基地 (悬停飞机)

- 操作: 点击 "重置"
- 操作: 选择飞机类型为 "悬停 (CanHover)"
- 操作: 点击 "模拟无基地" 按钮 (所有基地变灰色)
- 操作: 点击 "返航"
- 观察点:
  - 飞机找不到可用基地
  - 状态变为 "circling"
  - 飞机在最近的基地附近盘旋
  - 无目标线显示
  - 盘旋轨迹为圆形
- 预期: ✅ 悬停飞机在基地附近盘旋等待

### 4. 步骤三: 无可用基地 (非悬停飞机)

- 操作: 点击 "重置"
- 操作: 选择飞机类型为 "固定翼 (非VTOL)"
- 操作: 确认 "模拟无基地" 仍激活
- 操作: 点击 "返航"
- 观察点:
  - 飞机找不到可用基地
  - 状态变为 "flyidle"
  - 飞机以 idleSpeed 做圆形盘旋
  - 75 ticks 后停止，状态变为 "idle"
- 预期: ✅ 非悬停飞机执行 FlyIdle 盘旋 75 ticks

### 5. 步骤四: FlyIdle 独立测试

- 操作: 点击 "重置"
- 操作: 点击 "盘旋 (FlyIdle)" 按钮
- 观察点:
  - 飞机开始盘旋
  - 状态显示 "flyidle"
  - 每 tick 转向约 90° (256 WAngle)
  - 飞行轨迹为圆形
  - 75 ticks 后自动停止
- 预期: ✅ FlyIdle 圆形盘旋，75 ticks 后停止

### 6. 步骤五: 恢复基地后返航

- 操作: 点击 "模拟无基地" 按钮恢复基地 (变回绿色)
- 操作: 点击 "返航"
- 观察点:
  - 飞机找到可用基地
  - 绿色目标线出现
  - 成功返航着陆
- 预期: ✅ 恢复基地后正常返航

### 7. 边界/异常测试

- **边界 A - 飞机已在基地上**: 将飞机放在基地上方后点击返航
  - 预期: ✅ 立即开始着陆/补给

- **边界 B - 快速重置**: 返航中点击 "重置"
  - 预期: ✅ 飞机立即回到起点，清除所有轨迹

- **边界 C - 切换飞机类型**: 返航过程中切换飞机类型
  - 预期: ✅ 类型切换影响后续行为 (VTOL/非VTOL 着陆方式改变)
