## 测试目标

本测试页面验证 Move 活动系统的核心视觉行为：
1. 路径跟随：单位沿 A* 计算的最短路径逐格移动
2. 两段式移动：MoveFirstHalf (fromCell -> betweenCells) + MoveSecondHalf (betweenCells -> toCell center)
3. WAngle 朝向系统：0 = 北 (-Z)，逆时针递增，256 = 西，512 = 南，768 = 东
4. 转向行为：进入新格前单位先转向目标方向
5. 障碍物绕行：路径自动重新计算以避开障碍

## B. 期望结果（可量化验收标准）

### 期望 1: 路径跟随正确性

**操作**: 点击地面任意可行走格子设置目标。

**量化标准**:
- 单位沿黄色路径线指示的路线移动，**不穿越障碍物**（灰色方块）
- 路径长度等于 A* 计算的最短路径格数（含起点和终点）
- 每格移动分为两段：从当前格中心到两格中点（firstHalf），再从中点到目标格中心（secondHalf）
- 1x 速度下单位移动速率约 **2 格/秒**（60fps 下每帧约 0.033 格）
- 到达目标格后单位停止，状态显示为「空闲」

**失败判定**: 单位穿越障碍物或路径非最短 → **BLOCKER**

### 期望 2: 朝向与转向行为

**操作**: 设置一个需要多次转向的目标（如迷宫场景中的远端目标）。

**量化标准**:
- 白色箭头指示器始终指向单位当前朝向（WAngle 映射正确）
- WAngle 约定：0 = 北（-Z 方向），256 = 西（-X 方向），512 = 南（+Z 方向），768 = 东（+X 方向）
- 进入新格前，单位先完成转向（状态显示「转向中」），转向速率约 **256 WAngle/秒**（90°/秒）
- 转向时白色箭头平滑旋转，**无跳变**（每帧转向量 ≤ 4 WAngle 单位）
- 转向完成后才开始移动（状态从「转向中」→「移动前半段」）

**失败判定**: 朝向箭头与移动方向不一致，或转向跳变 > 10 WAngle/帧 → **MAJOR**

### 期望 3: 两段式移动连续性

**操作**: 在空场景中设置一个 10 格距离的目标，以 1x 速度观察。

**量化标准**:
- 移动分为两个连续阶段：前半段（fromCell center → betweenCells）+ 后半段（betweenCells → toCell center）
- 两个阶段之间**无停顿、无位置跳变**
- carryover progress 正确传递：若前半段结束时 progress 超出 distance，超出部分应作为后半段的起始 progress
- 单位位置每帧连续变化，**无瞬移**（相邻帧位置差 ≤ 0.04 世界单位）
- 状态栏显示当前移动阶段的完成百分比（文本形式）

**失败判定**: 两个阶段间出现可见停顿或位置跳变 → **MAJOR**

### 期望 4: 障碍物绕行

**操作**: 选择「迷宫场景」或「随机障碍」预设，点击远端目标。

**量化标准**:
- 路径自动绕行障碍物（灰色方块），**不穿越不可行走格子**
- 切换障碍物（Ctrl+点击）后，若当前路径被阻断，单位应重新计算路径
- 目标被完全阻挡时，单位停止在可达的最近格，状态显示「空闲」
- 路径重新计算耗时 < **100ms**（20x20 网格）

**失败判定**: 单位穿越障碍物或无法到达可达目标 → **BLOCKER**

### 期望 5: 速度控制响应

**操作**: 分别点击 1x / 2x / 4x 速度按钮，观察同一目标的移动时间。

**量化标准**:
- 1x 速度：10 格距离约 **5 秒**完成
- 2x 速度：10 格距离约 **2.5 秒**完成
- 4x 速度：10 格距离约 **1.25 秒**完成
- 速度切换即时生效，无需重新设置目标
- 暂停/恢复按钮即时生效（空格键快捷键）

**失败判定**: 速度倍数与实际移动时间不成反比 → **MAJOR**

## 检验流程

### 准备工作

1. 打开测试页面：`http://localhost:5173/test/activities/move/`
2. 确认环境信息栏显示 WebGL 2.0
3. 确认 FPS 显示在 50-60 范围
4. 确认网格显示为 20x20

### 步骤一：基础路径跟随

1. 在空场景中点击地面任意位置设置目标
2. 观察黄色路径线是否正确显示
3. 观察单位沿路径移动，不穿越任何格子边界
4. 确认状态栏显示：「移动前半段」→「移动后半段」→「空闲」

**预期**: ✅ 符合期望 1

### 步骤二：朝向验证

1. 设置一个需要多次转向的目标（如对角线远端）
2. 观察白色箭头指示器方向
3. 确认箭头始终指向移动方向
4. 在状态「转向中」时，确认单位不移动只旋转

**预期**: ✅ 符合期望 2

### 步骤三：两段式移动

1. 设置一个 10 格距离的目标
2. 以 1x 速度观察完整移动过程
3. 确认单位连续移动，无停顿
4. 观察进度条从 0% 到 100% 连续变化

**预期**: ✅ 符合期望 3

### 步骤四：障碍物绕行

1. 点击「迷宫场景」按钮
2. 点击迷宫远端的目标
3. 确认路径绕行灰色障碍方块
4. Ctrl+点击切换一个路径上的障碍物
5. 确认路径重新计算

**预期**: ✅ 符合期望 4

### 步骤五：速度控制

1. 设置一个固定目标，记录 1x 速度下的完成时间
2. 切换到 2x 速度，重新设置同一目标，确认时间减半
3. 切换到 4x 速度，确认时间再减半
4. 点击「暂停」，确认单位停止
5. 点击「恢复」或按空格键，确认单位继续移动

**预期**: ✅ 符合期望 5

### 边界/异常测试

1. **快速连续点击目标**：连续点击多个不同位置 → 单位依次前往，无崩溃
2. **目标在障碍物上**：点击灰色方块位置 → 单位不移动或寻找最近可达格
3. **单位在障碍物上**：尝试将单位起始位置设为障碍物（不可操作，验证保护）
4. **极端速度**：4x 速度下长距离移动 → 无位置跳变或穿墙
