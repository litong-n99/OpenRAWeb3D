# 飞行活动 - Fly + FlyForward 验收测试

**审核状态**: 待审核 (Pending Review)
**创建日期**: 2026-06-16
**对应模块**: `src/OpenRA.Mods.Common/Activities/Air/Fly.ts`, `src/OpenRA.Mods.Common/Activities/Air/FlyForward.ts`

## 期望结果 (Expected Results)

1. **目标追踪 (Fly)**:
   - 飞机朝向目标点飞行，每 tick 朝向通过 `WAngle.tickFacing()` 逐步旋转。
   - 可量化指标: `WAngle 0 = 北 (负 Z 方向)`，逆时针递增。256 = 东，512 = 南，768 = 西。
   - 可量化指标: 巡航高度 = `1280 WDist` (约 1.25 世界单位)。飞机在飞行中保持此高度。
   - 可量化指标: 到达目标点水平距离 < `120 WDist` (约 1.5 倍步长) 时停止。

2. **高度维持**:
   - VTOL 飞机: 垂直起降，先上升到巡航高度再水平移动。
   - 非 VTOL 飞机: 边飞边爬升，不能垂直起降。
   - 可量化指标: 高度偏差 < `64 WDist` (约 0.06 世界单位) 视为达标。

3. **转向半径 (非VTOL)**:
   - 可量化指标: 转向半径 `r = 180 * speed / turnSpeed`。speed=80, turnSpeed=32 → `r = 450 WDist`。
   - 可量化指标: 当目标位于转向圆内时，飞机保持当前 facing 继续飞行，不强行转向。
   - 可量化指标: 悬停飞机 (CanHover) 无转向半径限制，可原地转向。

4. **目标线 (TargetLineNode)**:
   - 可量化指标: 飞机与目标之间显示红色线条，颜色值 `#FF0000` (RGB 255, 0, 0)。
   - 可量化指标: 线条宽度约 2-3 像素，持续更新直到飞机到达目标。

5. **FlyForward (直飞)**:
   - 可量化指标: 飞机沿当前 facing 直飞 `50 ticks` 或 `3000 WDist`。
   - 可量化指标: 不追踪目标，不响应目标位置变化。
   - 可量化指标: 飞行轨迹为直线，偏差 < `32 WDist`。

## 检验流程

### 1. 准备工作

- 打开测试页面: `http://localhost:5173/test/activities/fly/`
- 确认环境信息栏显示 "引擎: WebGL 2.0"
- 设置屏幕分辨率为 1920×1080 (1x 缩放)
- 确认页面显示绿色地形网格和一架灰色飞机模型

### 2. 步骤一: Fly 目标追踪 (VTOL)

- 操作: 选择飞机类型为 "VTOL (垂直起降)"
- 操作: 点击 "点击设置目标" 按钮，然后在画布上点击一个较远的目标点
- 观察点:
  - 飞机先垂直上升，达到约 1280 WDist 高度后开始水平移动
  - 飞机朝向目标旋转 (WAngle 逐步变化)
  - 红色目标线从飞机指向目标点
  - 状态栏显示 "追踪目标中"
- 预期: ✅ VTOL 先垂直上升再水平飞行，目标线红色可见

### 3. 步骤二: Fly 目标追踪 (固定翼)

- 操作: 点击 "重置位置"，选择飞机类型为 "固定翼 (非VTOL)"
- 操作: 点击画布设置一个目标点
- 观察点:
  - 飞机边飞边爬升，不是垂直起降
  - 飞机有最小转向半径，不能急转弯
  - 当目标很近时，如果目标在转向圆内，飞机会飞过再转回
  - 飞行轨迹有平滑的弧线
- 预期: ✅ 非VTOL 飞机有转向半径限制，轨迹平滑

### 4. 步骤三: FlyForward 直飞

- 操作: 点击 "重置位置"
- 操作: 切换模式为 "FlyForward (直飞)"
- 操作: 点击 "点击设置目标" (此时目标只是触发起点，飞机沿当前 facing 直飞)
- 观察点:
  - 飞机沿当前 facing 直线飞行
  - 不追踪目标点位置
  - 飞行 50 ticks 或 3000 WDist 后停止
  - 状态栏显示 "直飞中 (X/50)"
- 预期: ✅ 飞机沿直线飞行，不追踪目标

### 5. 步骤四: 悬停飞机 (CanHover)

- 操作: 点击 "重置位置"，选择飞机类型为 "悬停 (CanHover)"
- 操作: 设置目标点
- 观察点:
  - 飞机可以原地转向 (无转向半径限制)
  - 可以悬停 (速度较慢)
  - 到达目标后停止
- 预期: ✅ 悬停飞机可原地转向，速度较慢

### 6. 边界/异常测试

- **边界 A - 近距离目标**: 设置目标点非常靠近飞机 (1-2 个机身长度)
  - 预期: ✅ 飞机到达目标后停止，不绕圈

- **边界 B - 飞机在目标转向圆内**: 非VTOL 模式下设置目标在飞机正侧方很近
  - 预期: ✅ 飞机继续当前 facing 飞行，绕过目标后再转回

- **边界 C - 重置**: 飞行中点击 "重置位置"
  - 预期: ✅ 飞机立即回到原点，清除轨迹和目标线

- **边界 D - 多次设置目标**: 飞行中再次点击设置新目标
  - 预期: ✅ 飞机转向新目标，目标线更新
