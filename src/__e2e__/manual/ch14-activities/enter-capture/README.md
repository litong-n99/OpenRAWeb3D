## 测试目标

本测试页面验证 Enter + CaptureActor 活动系统的核心视觉行为：
1. **Enter 4 状态状态机**：Approaching -> Entering -> Exiting -> Finished
2. **CaptureActor 占领逻辑**：工程师接近建筑 -> 进入 -> 占领/破坏 -> 退出
3. **tickInner 钩子**：验证目标是否仍可被占领（目标死亡、归属变更时取消）
4. **tryStartEnter 钩子**：验证占领条件，启动占领流程
5. **onEnterComplete 钩子**：完成占领、归属变更、工程师处置
6. **目标线渲染**：Enter 使用绿色 (#44CC44) 目标线
7. **消耗式 vs 非消耗式占领**：工程师是否被消耗
8. **破坏模式**：HP 高于阈值时破坏而非占领

## B. 期望结果（可量化验收标准）

### 期望 1: 接近阶段 (Approaching)

**操作**: 点击"基础占领"预设，或点击"开始占领"按钮。

**量化标准**:
- 工程师沿最短路径移动到目标建筑相邻格，移动速度约 **0.025 格/帧** (1x 速度)
- 状态栏显示"接近中" (EnterState.Approaching = 0)
- 目标线显示为 **#44CC44**（绿色）虚线，从工程师指向建筑
- 工程师模型为蓝色方块 + 顶部黄色小球标识
- 建筑模型为红色方块（敌方归属）

**失败判定**: 工程师不移动或移动方向错误 -> **BLOCKER**

### 期望 2: 进入阶段 (Entering)

**操作**: 观察工程师到达建筑相邻格后的行为。

**量化标准**:
- 到达相邻格后状态变为"进入中" (EnterState.Entering = 1)
- 工程师继续移动到建筑所在格中心，与建筑模型重叠
- 进入完成后触发占领/破坏逻辑
- 进入过程中目标线保持显示

**失败判定**: 工程师到达相邻格后停止不进入建筑 -> **BLOCKER**

### 期望 3: 占领结果 (Capture)

**操作**: 在"基础占领"预设中观察完整占领流程。

**量化标准**:
- 占领成功后建筑归属从"敌方"变为"己方"
- 建筑颜色从 **#E94560**（红色）变为 **#44CC44**（绿色）
- 屏幕中央显示 **"CAPTURED!"** 红色大字提示，持续 2 秒
- 状态栏显示"占领完成"
- 工程师退出到相邻格（非消耗模式）

**失败判定**: 占领完成后建筑颜色不变或归属未变更 -> **BLOCKER**

### 期望 4: 消耗式占领 (Consumed)

**操作**: 点击"消耗式占领"预设。

**量化标准**:
- 工程师进入建筑后完成占领
- 占领完成后工程师 **消失**（模型不可见，setEnabled(false)）
- 状态栏显示"已消耗"
- 建筑归属变更，颜色变绿
- 屏幕中央显示"CAPTURED!"

**失败判定**: 消耗式占领后工程师仍然可见 -> **MAJOR**

### 期望 5: 破坏模式 (Sabotage)

**操作**: 点击"破坏模式"预设。

**量化标准**:
- 建筑初始 HP = 80（高于破坏阈值 50%）
- 工程师进入后触发破坏而非占领
- 建筑 HP 减少 **25%**（从 80 降至 55）
- 屏幕中央显示 **"SABOTAGED!"** 红色大字提示
- 建筑归属 **不变**（仍为敌方）
- 工程师根据 consumed 设置决定是否保留

**失败判定**: 破坏模式下建筑归属变更或 HP 未减少 -> **MAJOR**

### 期望 6: 取消占领 (Cancel)

**操作**: 点击"取消占领"预设，或在占领过程中点击"取消占领"按钮。

**量化标准**:
- 目标无效时（canBeCaptured = false），工程师停止移动
- 状态变为"已完成" (EnterState.Finished = 3)
- 目标线立即消失
- 工程师不进入建筑
- 建筑归属不变

**失败判定**: 目标无效后工程师仍继续移动 -> **MAJOR**

### 期望 7: 目标线颜色与行为

**操作**: 观察任意预设场景中的目标线。

**量化标准**:
- Enter 活动的目标线颜色为 **#44CC44**（绿色），与 Move 的蓝色不同
- 目标线为虚线样式（dash 0.25 + gap 0.12 世界单位）
- 占领完成后目标线 **立即消失**
- 目标线始终从工程师中心指向建筑中心

**失败判定**: 目标线颜色错误或不随状态变化 -> **MINOR**

## 检验流程

### 准备工作

1. 打开测试页面：`http://localhost:5173/test/ch14-activities/enter-capture/`
2. 确认环境信息栏显示 WebGL 2.0
3. 确认 FPS 显示在 50-60 范围
4. 确认网格显示为 20x20

### 步骤一：基础占领流程

1. 点击"基础占领"预设按钮
2. 观察工程师（蓝色）向建筑（红色）移动
3. 确认状态栏显示"接近中"
4. 观察工程师到达建筑相邻格后进入建筑
5. 确认状态变为"进入中" -> "退出中" -> "已完成"
6. 确认建筑颜色从红变绿，归属变为"己方"
7. 确认屏幕显示"CAPTURED!"

**预期**: 符合期望 1、2、3

### 步骤二：消耗式占领

1. 点击"消耗式占领"预设按钮
2. 观察工程师移动、进入建筑
3. 确认占领完成后工程师消失
4. 确认状态栏显示"已消耗"
5. 确认建筑颜色变绿

**预期**: 符合期望 4

### 步骤三：破坏模式

1. 点击"破坏模式"预设按钮
2. 观察工程师移动、进入建筑
3. 确认屏幕显示"SABOTAGED!"而非"CAPTURED!"
4. 确认建筑 HP 从 80 降至 55
5. 确认建筑归属仍为"敌方"，颜色仍为红色

**预期**: 符合期望 5

### 步骤四：取消占领

1. 点击"取消占领"预设按钮
2. 观察工程师不移动（目标已无效）
3. 确认状态栏显示"已完成"
4. 确认目标线不存在
5. 或在基础占领过程中点击"取消占领"按钮，确认工程师停止

**预期**: 符合期望 6

### 步骤五：手动交互

1. 左键点击地面移动工程师到不同位置
2. 右键点击地面移动建筑到不同位置
3. 点击"开始占领"按钮启动占领流程
4. 观察工程师自动寻路到建筑并完成占领

**预期**: 符合期望 1、2、3

### 边界/异常测试

1. **快速切换预设**：连续点击不同预设按钮 -> 场景正确重置，无崩溃
2. **建筑在地图边缘**：右键点击地图边缘设置建筑 -> 工程师正确处理边界
3. **工程师在建筑上开始**：左键点击建筑格设置工程师 -> 直接进入 Entering 状态
4. **暂停中占领**：暂停状态下点击"开始占领" -> 工程师不移动，恢复后继续
5. **多次占领**：完成一次占领后重置再占领 -> 流程可重复
