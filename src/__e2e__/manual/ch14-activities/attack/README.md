## 测试目标

本测试页面验证 Attack 活动系统的核心视觉行为：
1. **射程检测与自动移动**：目标在射程外时，单位自动移动进入射程
2. **转向与开火**：单位必须先转向面对目标才能开火
3. **AttackStatus 状态流转**：UnableToAttack -> NeedsToMove -> NeedsToTurn -> Attacking
4. **目标线渲染**：红色虚线 (#E94560) 从单位指向目标
5. **最小射程行为**：目标在最小射程内时，单位后退拉开距离
6. **WAngle 朝向系统**：0 = 北 (-Z)，逆时针递增，256 = 西，512 = 南，768 = 东

---

## B. 期望结果（可量化验收标准）

### 期望 1: 射程检测与自动移动

**操作**: 选择"目标在射程外"预设，或点击远处地面设置目标。

**量化标准**:
- 目标距离 > 射程格数时，AttackStatus 显示为"需要移动" (NeedsToMove = 2)
- 单位沿最短路径自动移动，移动速度约 **0.025 格/帧** (1x 速度)
- 单位进入射程后（距离 <= 射程格数），状态自动变为"需要转向"或"攻击中"
- 无需人工干预，移动 -> 攻击流程全自动完成
- 目标线（红色虚线）始终从单位指向目标，实时更新

**失败判定**: 目标在射程外但单位不移动，或移动后未自动转为攻击状态 -> **BLOCKER**

### 期望 2: 转向与开火

**操作**: 选择"目标在射程内但需转向"预设，或设置一个背对目标的起始朝向。

**量化标准**:
- 目标在射程内但朝向偏差 > 64 WAngle（约 22.5 度）时，状态显示"需要转向" (NeedsToTurn = 1)
- 转向使用 **最短弧**：WAngle 差值 > 512 时走反方向（WAngle.tickFacing 行为）
- 转向速率由 turnSpeed 控制：慢速 = 4 WAngle/帧，正常 = 8，快速 = 16
- 转向完成后状态变为"攻击中" (Attacking = 3)，屏幕中央出现 **"FIRE" 红色闪烁**
- 每次开火目标 HP 减少 10，HP 条颜色从绿 -> 黄 -> 红渐变
- 开火冷却间隔为 **20 帧**（约 333ms @ 60fps）

**失败判定**: 单位不转向直接开火，或转向方向不是最短弧 -> **MAJOR**

### 期望 3: WAngle 朝向系统正确性

**操作**: 观察白色箭头指示器方向与 WAngle 数值的对应关系。

**量化标准**:
- WAngle 0 = 北（-Z 方向），箭头指向屏幕上方
- WAngle 256 = 西（-X 方向），箭头指向屏幕左侧
- WAngle 512 = 南（+Z 方向），箭头指向屏幕下方
- WAngle 768 = 东（+X 方向），箭头指向屏幕右侧
- 状态栏显示当前 WAngle 值和对应的角度（度）
- 转向时箭头 **平滑旋转**，无跳变（每帧变化量 <= turnSpeed）

**失败判定**: 箭头方向与 WAngle 数值不匹配 -> **BLOCKER**

### 期望 4: 目标线渲染

**操作**: 观察任意预设场景中从单位到目标的连线。

**量化标准**:
- 目标线颜色为 **#E94560**（红色），与 AttackMove 目标线颜色一致
- 目标线为 **虚线样式**（dash 0.25 + gap 0.12 世界单位）
- 目标线随单位移动 **实时更新**（每帧重建起点）
- 目标死亡或无效后，目标线 **立即消失**（无残留）
- 目标线始终从单位中心 (y=0.3) 指向目标中心 (y=0.3)

**失败判定**: 目标线颜色错误、不随移动更新、或目标死亡后残留 -> **MAJOR**

### 期望 5: 最小射程行为

**操作**: 选择"目标在最小射程内"预设。

**量化标准**:
- 最小射程内显示橙色内环（minRangeRing），直径 = minRange * 2 格
- 目标在最小射程内时，单位 **后退** 拉开距离
- 后退到位后自动转为攻击状态
- 状态栏显示"需要移动"（后退也是移动的一种）

**失败判定**: 目标在最小射程内但单位不后退，或后退后仍不开火 -> **MAJOR**

### 期望 6: 移动目标追击

**操作**: 选择"移动目标"预设。

**量化标准**:
- 目标沿巡逻路径移动时，单位 **持续追击**
- 目标移动出射程时，单位自动恢复移动状态
- 目标重新进入射程后，单位恢复攻击
- 追击过程中目标线始终指向当前目标位置

**失败判定**: 目标移动后单位不追击，或追击过程中崩溃 -> **BLOCKER**

## 检验流程

### 准备工作

1. 打开测试页面：`http://localhost:5173/test/ch14-activities/attack/`
2. 确认环境信息栏显示 WebGL 2.0
3. 确认 FPS 显示在 50-60 范围
4. 确认网格显示为 20x20

### 步骤一：射程检测与自动移动

1. 点击"目标在射程外"预设按钮
2. 观察状态栏显示"需要移动"
3. 观察蓝色单位向红色目标移动
4. 确认单位进入射程后状态变为"攻击中"
5. 确认出现"FIRE"闪烁，目标 HP 减少

**预期**: 符合期望 1

### 步骤二：转向与开火

1. 点击"目标在射程内但需转向"预设按钮
2. 观察状态栏显示"需要转向"
3. 观察白色箭头从朝下（WAngle 512）转向朝右（WAngle 768 或类似）
4. 确认转向完成后状态变为"攻击中"
5. 确认出现"FIRE"闪烁

**预期**: 符合期望 2

### 步骤三：WAngle 朝向验证

1. 右键点击地面设置单位到不同位置
2. 左键点击设置目标到不同位置
3. 观察白色箭头方向与状态栏 WAngle 数值的对应关系
4. 验证：0 = 北（上），256 = 西（左），512 = 南（下），768 = 东（右）

**预期**: 符合期望 3

### 步骤四：目标线验证

1. 在任意预设中观察红色虚线
2. 移动单位（右键点击）或移动目标（左键点击）
3. 确认目标线实时跟随更新
4. 将目标 HP 打到 0，确认目标线立即消失

**预期**: 符合期望 4

### 步骤五：最小射程

1. 点击"目标在最小射程内"预设
2. 观察橙色内环显示
3. 确认单位后退拉开距离
4. 后退到位后确认单位开始攻击

**预期**: 符合期望 5

### 步骤六：移动目标

1. 点击"移动目标"预设
2. 观察红色目标沿方形路径巡逻
3. 确认蓝色单位持续追击并攻击
4. 观察目标线始终指向移动中的目标

**预期**: 符合期望 6

### 边界/异常测试

1. **快速切换预设**：连续点击不同预设按钮 -> 场景正确重置，无崩溃
2. **目标在地图边缘**：点击地图边缘设置目标 -> 单位正确处理边界
3. **零射程**：设置射程为 0 -> 单位无法攻击，状态保持"无法攻击"
4. **极高转向速度**：设置 fast 转向 -> 单位几乎瞬间转向，无跳变
5. **暂停中开火**：暂停状态下 -> 单位不移动、不转向、不开火
