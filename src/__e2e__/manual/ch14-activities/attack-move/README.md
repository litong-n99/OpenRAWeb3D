## 测试目标

本测试页面验证 AttackMoveActivity 的核心视觉行为：
1. 移动中持续扫描敌人（AutoTarget.scanForTarget 模拟）
2. 发现敌人后中断当前移动，进入攻击状态
3. 扫描范围可视化（半透明圆环，颜色随状态变化）
4. 消灭敌人后自动恢复向原目标移动
5. 目标线（红色虚线）在中断期间保持指向原目标

---

## B. 期望结果（可量化验收标准）

### 期望 1: 攻击移动中断行为

**操作**: 选择「敌人中途拦截」预设，观察单位移动。

**量化标准**:
- 单位移动时持续扫描周围（每帧检测）
- 敌人进入扫描范围（默认 5 格）后，单位 **立即停止移动**
- 状态栏在 **1 帧内**从「移动中」变为「攻击中」
- 屏幕顶部显示红色警报提示「发现敌人！攻击移动中断」，持续 **1.5 秒**
- 攻击持续 **1 秒**（60 帧）后敌人被消灭
- 中断计数器正确累加

**失败判定**: 发现敌人后单位不停止或状态切换延迟 > 3 帧 → **BLOCKER**

### 期望 2: 扫描范围可视化

**操作**: 观察单位周围的扫描圆环。

**量化标准**:
- 扫描圆环为 **半透明圆环**（torus），线宽 0.03 世界单位
- 安全状态（无敌人）：圆环颜色 **绿色 (#44CC44)**，透明度 0.25
- 警戒状态（敌人在范围边缘）：圆环颜色 **黄色 (#FFCC00)**，透明度 0.4
- 交战状态（正在攻击）：圆环颜色 **红色 (#E94560)**，透明度 0.5
- 圆环直径 = 扫描格数 × 2.0 世界单位（5 格 = 直径 10）
- 切换扫描范围（3/5/8 格）后圆环大小 **即时变化**

**失败判定**: 圆环颜色与状态不匹配或大小不正确 → **MAJOR**

### 期望 3: 目标线保持

**操作**: 在攻击移动中断期间观察目标线。

**量化标准**:
- 攻击期间红色目标线 **保持显示**，始终指向原目标
- 目标线不从敌人位置出发（区别于普通 Attack）
- 目标线样式为虚线，颜色 **红色 (#E94560)**
- 到达原目标后目标线 **淡出消失**

**失败判定**: 攻击期间目标线消失或指向敌人 → **MAJOR**

### 期望 4: 恢复移动

**操作**: 观察敌人被消灭后的行为。

**量化标准**:
- 敌人被消灭后，单位在 **1 帧内**从「攻击中」变为「恢复移动」
- 恢复移动后单位继续向 **原目标**前进，不重置路径
- 状态栏依次显示：「攻击中」→「恢复移动」→「移动中」
- 若途中再次发现敌人，重复中断-攻击-恢复循环

**失败判定**: 消灭敌人后单位不恢复移动或目标改变 → **BLOCKER**

### 期望 5: 多敌人场景

**操作**: 选择「多敌人巡逻」预设，观察单位行为。

**量化标准**:
- 多个敌人同时在扫描范围内时，单位攻击最近的敌人
- 消灭一个敌人后若范围内仍有敌人，继续攻击下一个
- 中断计数器正确累加每次攻击事件
- 所有敌人被消灭后单位最终到达原目标
- 敌人按预设路径 **巡逻移动**（可见移动动画）

**失败判定**: 多敌人时单位行为异常或崩溃 → **BLOCKER**

## 检验流程

### 准备工作

1. 打开测试页面：`http://localhost:5173/test/activities/attack-move/`
2. 确认环境信息栏显示 WebGL 2.0
3. 确认 FPS 显示在 50-60 范围
4. 确认默认场景为「敌人中途拦截」预设

### 步骤一：基础中断行为

1. 观察蓝色单位从左侧出发向右侧目标移动
2. 等待单位接近中间位置的红色敌人
3. 确认单位进入扫描范围后停止移动
4. 确认屏幕顶部出现红色警报提示
5. 确认状态栏显示「攻击中」
6. 等待约 1 秒后确认敌人消失，单位恢复移动

**预期**: ✅ 符合期望 1

### 步骤二：扫描范围可视化

1. 观察单位周围的扫描圆环颜色
2. 确认初始为绿色（安全）
3. 当敌人接近时确认变为黄色（警戒）
4. 当单位开始攻击时确认变为红色（交战）
5. 点击「扫描 3 格」按钮，确认圆环缩小
6. 点击「扫描 8 格」按钮，确认圆环扩大

**预期**: ✅ 符合期望 2

### 步骤三：目标线保持

1. 在攻击期间观察红色目标线
2. 确认目标线始终指向原目标位置（右侧红色球体）
3. 确认目标线不从敌人位置出发
4. 确认目标线样式为虚线

**预期**: ✅ 符合期望 3

### 步骤四：恢复移动

1. 观察敌人被消灭后的单位行为
2. 确认单位继续向原目标移动
3. 确认状态栏依次变化：「攻击中」→「恢复移动」→「移动中」
4. 确认单位最终到达目标位置

**预期**: ✅ 符合期望 4

### 步骤五：多敌人场景

1. 点击「多敌人巡逻」按钮
2. 确认场景中出现 3 个红色敌人
3. 观察敌人按预设路径巡逻移动
4. 观察单位依次攻击进入范围的敌人
5. 确认中断计数器正确累加
6. 确认所有敌人被消灭后单位到达目标

**预期**: ✅ 符合期望 5

### 边界/异常测试

1. **快速重置**：连续点击「重置场景」10 次 → 无崩溃，状态正确重置
2. **切换扫描范围**：在移动中切换 3/5/8 格 → 圆环即时变化，行为正确
3. **目标在敌人堆中**：点击敌人位置设置目标 → 单位尽可能接近后攻击
4. **敌人远端出现**：选择「敌人远端出现」预设 → 单位先移动一段距离再被拦截
5. **直达路径**：选择「直达路径」预设 → 无敌人，单位直达目标
