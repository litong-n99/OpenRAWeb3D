## 测试目标

本测试页面验证 Turn 活动系统的核心视觉行为：
1. **最短弧转向**：单位始终沿最短弧转向目标方向
2. **WAngle 坐标系**：0 = 北 (-Z)，256 = 西 (-X)，512 = 南 (+Z)，768 = 东 (+X)
3. **转向速度控制**：turnSpeed 决定每帧最大转向量
4. **完成判定**：当前 facing == desiredFacing 时活动完成
5. **Mobile 禁用/暂停**：转向暂停等待
6. **取消行为**：isCanceling = true 时立即完成

## B. 期望结果（可量化验收标准）

### 期望 1: 最短弧转向

**操作**: 点击"转向正对面"预设（180° 转向），或点击"转向东"（从北 0 到东 768）。

**量化标准**:
- 从 WAngle 0（北）转向 768（东）时，单位应 **顺时针** 旋转（经过 1024/0 边界）
- 旋转路径差值应为 256 WAngle（90°），而非 768（270°）
- 红色弧线可视化显示实际旋转路径，应始终为 **最短弧**
- 从 WAngle 0 转向 512（南）时，差值为 512，可顺时针或逆时针（等长）
- 每帧转向量 ≤ turnSpeed，**无跳变**（相邻帧 facing 差值 ≤ turnSpeed）

**失败判定**: 单位走长弧而非短弧（如从 0 到 768 走了 768 而非 256） -> **BLOCKER**

### 期望 2: WAngle 坐标系正确性

**操作**: 依次点击北/东/南/西预设，观察白色箭头方向。

**量化标准**:
- WAngle 0 = 北（-Z 方向），箭头指向屏幕上方
- WAngle 256 = 西（-X 方向），箭头指向屏幕左侧
- WAngle 512 = 南（+Z 方向），箭头指向屏幕下方
- WAngle 768 = 东（+X 方向），箭头指向屏幕右侧
- 状态栏显示当前 WAngle 值和对应角度（度），格式：`WAngle (degrees°)`
- 右上角角度参考面板显示各方向对应的 WAngle 值

**失败判定**: 箭头方向与 WAngle 数值不匹配 -> **BLOCKER**

### 期望 3: 转向速度

**操作**: 分别设置慢速(4)、正常(8)、快速(16)、瞬间(256)转向速度，观察同一目标（如从北到南）的完成时间。

**量化标准**:
- 慢速 (4/帧)：512 WAngle 差值需 **128 帧**（约 2.1 秒 @ 60fps）
- 正常 (8/帧)：512 WAngle 差值需 **64 帧**（约 1.1 秒）
- 快速 (16/帧)：512 WAngle 差值需 **32 帧**（约 0.5 秒）
- 瞬间 (256/帧)：512 WAngle 差值需 **2 帧**（约 33ms）
- 状态栏显示"完成帧数"，实际帧数应与理论值一致（±1 帧）
- 速度切换即时生效，正在进行的转向会重新计算完成帧数

**失败判定**: 实际完成帧数与理论值偏差 > 2 帧 -> **MAJOR**

### 期望 4: 完成判定

**操作**: 设置任意转向目标，等待完成。

**量化标准**:
- 当 `facing === desiredFacing` 时，状态显示"完成"（绿色）
- 完成时单位上方出现 **绿色小球** 标记
- 目标方向指示器（黄色钻石）消失
- 红色最短弧路径线消失
- 状态栏"总旋转次数"计数器 +1

**失败判定**: facing 已达目标但状态不显示完成 -> **BLOCKER**

### 期望 5: Mobile 禁用与暂停

**操作**: 在转向过程中点击"切换 Mobile 禁用"或"切换 Mobile 暂停"按钮。

**量化标准**:
- Mobile 禁用时，状态显示"禁用"（红色），单位 **停止转向**
- Mobile 暂停时，状态显示"暂停"（红色），单位 **停止转向**
- 禁用/暂停解除后，单位 **继续** 转向目标方向
- 禁用/暂停期间，当前 facing 值 **不变**
- 禁用/暂停期间，完成帧数计数器 **暂停**

**失败判定**: 禁用/暂停期间单位仍继续转向 -> **MAJOR**

### 期望 6: 点击地面转向

**操作**: 左键点击地面任意位置。

**量化标准**:
- 点击后单位计算从当前位置到点击位置的 WAngle 方向
- 单位立即开始转向该方向
- 黄色钻石指示器出现在目标方向 1.5 格处
- 红色弧线显示最短旋转路径
- 点击单位当前格（无方向）不触发转向

**失败判定**: 点击地面后单位不转向或转向错误方向 -> **BLOCKER**

## 检验流程

### 准备工作

1. 打开测试页面：`http://localhost:5173/test/ch14-activities/turn/`
2. 确认环境信息栏显示 WebGL 2.0
3. 确认 FPS 显示在 50-60 范围
4. 确认网格显示为 20x20
5. 确认右上角角度参考面板显示正确

### 步骤一：最短弧验证

1. 确保单位朝向为北（WAngle 0，箭头朝上）
2. 点击"转向东 (WAngle 768)"按钮
3. 观察红色弧线显示路径：应经过 1024/0 边界（顺时针）
4. 确认实际旋转差值为 256（而非 768）
5. 观察状态栏"剩余角度差"从 256 逐步减少到 0

**预期**: 符合期望 1

### 步骤二：WAngle 坐标系验证

1. 依次点击：北(0) -> 西(256) -> 南(512) -> 东(768) -> 北(0)
2. 每次确认白色箭头方向正确
3. 验证状态栏数值与箭头方向一致
4. 验证右上角参考面板数值正确

**预期**: 符合期望 2

### 步骤三：转向速度验证

1. 点击"转向南 (WAngle 512)"按钮
2. 记录完成帧数（状态栏显示）
3. 切换为"慢 (4/帧)"速度，重置，再次转向南
4. 确认完成帧数约为 128
5. 切换为"快 (16/帧)"速度，重置，再次转向南
6. 确认完成帧数约为 32
7. 切换为"瞬间 (256/帧)"速度，重置，再次转向南
8. 确认完成帧数约为 2

**预期**: 符合期望 3

### 步骤四：完成判定验证

1. 点击任意转向目标
2. 等待转向完成
3. 确认状态显示"完成"（绿色）
4. 确认单位上方出现绿色小球
5. 确认黄色钻石和红色弧线消失
6. 确认"总旋转次数"+1

**预期**: 符合期望 4

### 步骤五：禁用/暂停验证

1. 点击"转向南"按钮
2. 在转向过程中点击"切换 Mobile 禁用"
3. 确认单位停止转向，状态显示"禁用"
4. 再次点击"切换 Mobile 禁用"解除
5. 确认单位继续转向
6. 重复测试"切换 Mobile 暂停"

**预期**: 符合期望 5

### 步骤六：点击地面转向

1. 左键点击地面不同位置（上、下、左、右、对角线）
2. 每次确认单位转向正确方向
3. 确认黄色钻石出现在目标方向
4. 确认红色弧线显示最短路径

**预期**: 符合期望 6

### 边界/异常测试

1. **连续快速转向**：连续点击不同方向 -> 单位依次完成，无崩溃
2. **360° 转向**：点击当前朝向方向 -> 立即完成（0 帧）
3. **超大 WAngle**：通过键盘或代码设置 WAngle > 1024 -> 正确归一化到 [0, 1024)
4. **零转向速度**：设置 turnSpeed = 0 -> 单位永不完成（或立即完成如果已在目标）
5. **移动中转向**：右键点击移动单位位置，然后左键点击目标 -> 单位在新位置正确转向
