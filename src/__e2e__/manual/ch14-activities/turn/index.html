B. 期望结果

1. 最短弧转向

  • 单位始终沿最短弧转向目标方向
  • WAngle 差值 > 512 时走反方向（如从 0 到 768 应顺时针而非逆时针）
  • 每帧转向量 ≤ turnSpeed，无跳变

2. WAngle 坐标系

  • 0 = 北 (-Z)，256 = 西 (-X)，512 = 南 (+Z)，768 = 东 (+X)
  • 白色箭头指示器方向与 WAngle 数值严格对应
  • 状态栏显示当前 WAngle 值和对应角度（度）

3. 完成判定

  • 当前 facing == desiredFacing 时活动完成，状态显示"完成"
  • Mobile 禁用时转向暂停（状态显示"禁用"）
  • 取消时立即完成（isCanceling = true）
