# 起降活动 - TakeOff + Land 验收测试

**审核状态**: ✅ 全部审核通过 (自动化验收测试 Playwright, 2026-07-03, 18/18 通过, 100%)
**创建日期**: 2026-06-16
**对应模块**: `src/OpenRA.Mods.Common/Activities/Air/TakeOff.ts`, `src/OpenRA.Mods.Common/Activities/Air/Land.ts`

## 期望结果 (Expected Results)

1. **VTOL 起飞 (TakeOff)**:
   - 飞机从地面垂直上升，无水平位移。
   - 可量化指标: 巡航高度 = `1280 WDist`。上升速率 = `64 WDist/tick` (altitudeVelocity)。
   - 可量化指标: 到达巡航高度时水平位置偏差 < `32 WDist`。

2. **VTOL 降落 (Land)**:
   - 水平对准停机坪 → 转向 → 垂直下降。
   - 可量化指标: 落点水平偏差 < `64 WDist` (约 0.06 世界单位)。
   - 可量化指标: 着陆时高度 = `landAltitude` (默认 0 WDist)。
   - 可量化指标: 着陆触发音效事件 (控制台输出 "landing sound")。

3. **非VTOL 起飞**:
   - 边飞边爬升，有水平位移。
   - 可量化指标: 到达巡航高度时水平位移 > `200 WDist` (已向前飞行)。
   - 可量化指标: 爬升角由 `maximumPitch` 限制 (约 45°)。

4. **非VTOL 降落进近轨迹**:
   - 计算 waypoints w1, w2, w3 形成弧线进近。
   - 可量化指标: 进近轨迹显示黄色/橙色/红色航路点标记。
   - 可量化指标: 落点水平偏差 < `128 WDist`。
   - 可量化指标: 转向半径 `r = 180 * speed / turnSpeed` 影响进近弧线曲率。

5. **完整周期**:
   - 起飞 → 巡航 → 进近 → 降落，全程轨迹连贯无跳变。
   - 可量化指标: 轨迹线颜色一致 (蓝色)，无断裂。

## 检验流程

### 1. 准备工作

- 打开测试页面: `http://localhost:5173/test/activities/land-takeoff/`
- 确认环境信息栏显示 "引擎: WebGL 2.0"
- 设置屏幕分辨率为 1920×1080 (1x 缩放)
- 确认页面显示绿色地形网格、绿色停机坪、灰色飞机

### 2. 步骤一: VTOL 垂直起飞

- 操作: 选择飞机类型为 "VTOL (垂直起降)"
- 操作: 点击 "起飞 (TakeOff)" 按钮
- 观察点:
  - 飞机垂直上升，X/Z 坐标几乎不变
  - 高度值从 0 逐步增加到 1280 WDist
  - 状态栏显示 "takeoff" 和当前高度
  - 达到巡航高度后状态变为 "cruise"
- 预期: ✅ VTOL 垂直上升，无水平位移，高度 = 1280 WDist

### 3. 步骤二: VTOL 垂直降落

- 操作: 点击 "降落 (Land)" 按钮 (或先起飞后降落)
- 观察点:
  - 飞机水平飞向停机坪 (绿色方块)
  - 到达停机坪上方后垂直下降
  - 落点与停机坪中心偏差 < 64 WDist
  - 着陆后高度 = 0 WDist
  - 控制台输出 "[Land] Landing sound triggered"
- 预期: ✅ VTOL 水平对准后垂直降落，精确着陆

### 4. 步骤三: 非VTOL 起飞

- 操作: 点击 "重置"，选择飞机类型为 "固定翼 (非VTOL)"
- 操作: 点击 "起飞"
- 观察点:
  - 飞机边向前飞边爬升
  - 到达巡航高度时已有明显水平位移
  - 飞行轨迹为向上倾斜的直线
- 预期: ✅ 非VTOL 边飞边升，有水平位移

### 5. 步骤四: 非VTOL 进近降落

- 操作: 点击画布设置新的停机坪位置 (可选)
- 操作: 点击 "降落"
- 观察点:
  - 出现黄色(w1)、橙色(w2)、红色(w3) 航路点标记
  - 出现黄色进近轨迹线
  - 飞机依次经过 w1 → w2 → w3 → 停机坪
  - 飞行轨迹为平滑弧线
  - 落点偏差 < 128 WDist
- 预期: ✅ 非VTOL 沿弧线进近，航路点正确

### 6. 步骤五: 完整周期

- 操作: 点击 "重置"
- 操作: 点击 "完整周期 (起飞→飞行→降落)"
- 观察点:
  - 自动起飞 → 巡航 → 进近 → 降落
  - 全程轨迹连贯，无跳变
  - 蓝色轨迹线完整显示整个飞行路径
- 预期: ✅ 完整周期流畅，轨迹连贯

### 7. 边界/异常测试

- **边界 A - 近距离降落**: 设置停机坪在飞机旁边 (< 500 WDist)
  - 预期: ✅ VTOL 直接水平移动后垂直降落；非VTOL 可能无法完成进近，需观察行为

- **边界 B - 重置**: 飞行中点击 "重置"
  - 预期: ✅ 飞机立即回到原点，清除所有轨迹和航路点

- **边界 C - 切换类型**: 起飞过程中切换飞机类型
  - 预期: ✅ 类型切换影响后续行为 (VTOL/非VTOL 模式改变)
