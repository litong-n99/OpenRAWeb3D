## 期望结果 (Expected Results)

1. **右键菜单抑制 (Context Menu Suppression)**: 在 Babylon.js 画布上单击鼠标右键时，浏览器原生上下文菜单不应弹出。
   - 可量化指标: 右键后 0ms 内 `contextmenu` 事件被 `preventDefault()` 阻止，菜单绝不出现
   - 覆盖范围: 整个 `<canvas>` 元素区域

2. **单击选择 (Single-Click Selection)**: 点击玩家拥有的彩色实体盒，该实体 ID 出现在状态面板"已选择"栏中。
   - 可量化指标: 点击后状态面板在 **100ms** 内更新显示被点击实体的 ID
   - 单选行为: 点击 `inf-1` 红色盒，状态面板显示 `inf-1`；再点击 `veh-1` 蓝色盒，选择替换为 `veh-1`
   - 点击空地: 在实体之间的地面区域点击，选择被清除，"已选择"显示 `(无)`

3. **拖拽框选 (Drag-Box Selection)**: 在实体上方拖拽鼠标画出矩形，矩形内所有实体被选中。
   - 可量化指标: 从 `inf-1` 左上方拖拽到 `inf-2` 右下方，框内同时包含两个 Infantry 实体
   - 可量化指标: 拖拽距离超过死区阈值 **5px** 后开始框选，小于 5px 视为单击
   - 可观测: 拖拽时出现绿色虚线矩形 (#4a9)，松开后显示框内实体 ID
   - 无实体框: 在空地拖拽，不应选中任何实体 (除非符合 #2 空地规则)

4. **双击同类选择 (Double-Click Select-by-Class)**: 双击一个实体，所有相同 `selectionClass` 的实体被同时选中。
   - 可量化指标: 两次点击间隔 < **300ms** 且位移 < **5px** 半径时触发双击
   - 示例: 双击红色 `inf-1`，状态面板应显示 `inf-1, inf-2` (两个 Infantry 都被选中)
   - 注意: 敌方 Infantry (`enm-i`) 不应被选中 (eligiblePlayers 不包含 "enemy")

5. **右键命令分发 (Right-Click Order Dispatch)**: 右键点击实体触发 "Attack" 命令，右键点击空地触发 "Move" 命令。
   - 可量化指标: 右键点击 `inf-1` 红色实体 → "最近命令"显示 `Attack → 实体 inf-1`
   - 可量化指标: 右键点击实体间空地 → "最近命令"显示 `Move → 地面 (x.xx, z.xx)`
   - 可观测: 状态面板"最近动作"栏在右键后 **100ms** 内更新

6. **悬停轮询 (Mouse-Over Rollover)**: 鼠标在实体上方移动时，状态面板"悬停中"栏实时更新。
   - 可量化指标: 鼠标移动到 `veh-1` 上方时，"悬停中"栏在 **1 帧** (~16ms) 内显示 `veh-1`
   - 可量化指标: 鼠标移开到空地时，"悬停中"栏显示 `(无)`
   - 可观测: 鼠标在相邻实体间快速移动，悬停栏跟随切换无延迟

7. **修饰键组合 (Modifier Key Combinations)**:
   - Shift+单击: 添加到现有选择 (不替换)
     - 先点 `inf-1` 选中，再 Shift+点击 `veh-1`，"已选择"显示 `inf-1, veh-1`
   - Ctrl+单击: 切换实体选择状态
     - 先选中 `inf-1, veh-1`，再 Ctrl+点击 `inf-1`，"已选择"变为 `veh-1` (移除 inf-1)
     - 再 Ctrl+点击 `str-1`，"已选择"变为 `veh-1, str-1` (添加 str-1)
   - 修饰键指示灯: 按下 Shift/Ctrl/Alt 时，顶部右侧对应按键指示灯变为绿色高亮

## 技术说明

### 坐标系统

- Controller 使用 `PointerEvent.clientX/clientY` 作为屏幕坐标
- Canvas 覆盖整个视口 (position:fixed, 0,0)，确保坐标无偏移
- 相机使用 ArcRotateCamera，键盘 (方向键) + 滚轮控制，不与鼠标交互冲突

### 状态机参考

```
IDLE → (左键按下) → MAYBE_DRAG → (移动 >5px) → DRAGGING → (释放) → IDLE
                                   ↘ (释放 <5px) → 单击选择 → IDLE
```
