期望结果 (Expected Results)

  • 右键菜单抑制: 在画布上右键单击，浏览器上下文菜单不应出现
  • 单击选择: 点击彩色实体，状态面板显示被点击的实体 ID，在 100ms 内更新
  • 拖拽框选: 拖拽穿过多个实体，状态面板显示框内所有实体 ID
  • 双击同类选择: 双击 Infantry 实体，所有 Infantry 实体同时被选中 (300ms 内)
  • 右键命令: 右键实体 → "Attack" 命令，右键地面 → "Move" 命令
  • 悬停轮询: 鼠标滑过实体，状态面板轮询区实时显示当前悬停实体
  • 修饰键组合: Shift+单击添加选择，Ctrl+单击切换选择
