# ResourceRenderer - 资源精灵密度与变体渲染验证

> **人工验收测试页**
> 模块: ResourceRenderer (资源精灵渲染器)
> 测试ID: `resource/rendering`
> OpenRA 对照: `ResourceRenderer.ts` (1,106 行) — lerpFrame 密度帧选择, cellVariantIndex 变体选择, TerrainSpriteLayer 管理
> 创建日期: 2026-06-14

---

## 测试目标

本测试页面验证 ResourceRenderer 的核心精灵渲染行为。ResourceRenderer 管理地形上的资源精灵层，每个 cell 根据其资源类型、密度（density）和变体（variant）渲染相应的 sprite frame。

自动化单元测试可以验证 `lerpFrame()` 的数学正确性、`cellVariantIndex()` 的哈希分布、`_addDirtyCell()` 的 dirty-tracking 逻辑，但以下关键行为必须由人工肉眼判断：

1. **精灵位置正确性**：资源精灵必须出现在正确的 cell 位置，与 18x12 网格对齐，无偏移或重叠。
2. **密度 → 帧映射视觉正确**：低密度 cell 显示稀疏/暗色精灵（小尺寸），高密度 cell 显示浓密/亮色精灵（大尺寸），中间密度应平滑过渡。
3. **变体渲染**：同一资源类型的相邻 cell 应显示视觉上可区分变体（色调偏移），每个 cell 的变体是确定性选择的（基于位置 hash）。
4. **多种资源类型共存**：Tiberium（绿）、Ore（金）、Spice（橙）、Gems（紫）四种类型应同时正确渲染，颜色不混合。
5. **空 cell 与有资源 cell 可辨**：空 cell 应以淡灰色低透明度显示，与有资源 cell 形成鲜明对比。

## B. 期望结果（可量化验收标准）

### 期望 1: 网格内精灵位置对齐准确

**操作**: 默认设置（条纹密度，最大密度 10，3 变体，四种资源类型全部可见），观察 18x12 资源网格。

**量化标准**:
| 检查项 | 预期值 | 容差 |
|--------|--------|------|
| 每行精灵数 | 18 个，均匀分布 | ±0 |
| 每列精灵数 | 12 个 | ±0 |
| 精灵中心偏移 | 与 cell 中心偏差 < cell 宽度的 5% | 无肉眼可察偏移 |
| 精灵无重叠 | 相邻精灵间可见间隙 | 间隙 > 2px（默认视角） |
| 地形底板可见 | 空 cell 处地形底板（深棕色）清楚可见 | — |

**失败判定**: 若精灵偏移导致明显错位（>10px）→ 坐标计算错误（BLOCKER）。若精灵大面积重叠 → 缩放计算错误（BLOCKER）。

### 期望 2: 密度驱动视觉变化平滑

**操作**: 默认「条纹」模式（密度逐行递增），从顶部（低密度）到底部（高密度）观察色彩和尺寸变化。

**量化标准**:
| 检查项 | 预期值 |
|--------|--------|
| 第 0 行颜色 | 明显暗于第 11 行（颜色亮度差 >= 30%） |
| 第 0 行精灵尺寸 | 明显小于第 11 行（尺寸差 >= 40%） |
| 第 5 行颜色 | 介于第 0 行和第 11 行之间（肉眼可辨渐变） |
| 行间跳跃 | 相邻行应有肉眼可辨颜色/尺寸差异 |
| 边界 cell | 边缘 cell（行/列 = 0 或 max-1）密度显著低于内部 cell |

**失败判定**: 若高密度行与低密度行视觉无差异 → 密度→帧 lerp 算法未生效（BLOCKER）。若某行视觉异常（跳跃/逆序）→ 数据索引错误（MAJOR）。

### 期望 3: 变体确定性分布

**操作**: 点击「高亮变体边界」按钮，观察变体边界 cell 是否以白色高亮显示。

**量化标准**:
| 检查项 | 预期值 |
|--------|--------|
| 变体边界可见 | 白色高亮 cell 出现在不同变体相邻处 |
| 边界连续性 | 变体边界形成连续的"区块"边界线 |
| 确定性 | 刷新后同一 cell 的变体不变（位置 hash 确定） |
| 变体数 1 | 选择「1 (无变体)」→ 重新生成 → 无白色边界（所有同类同变体） |
| 变体数 5 | 选择「5」→ 重新生成 → 更多可见边界，区块更小 |

**失败判定**: 若变体边界高亮在所有 cell 上出现 → 变体选择逻辑错误（MAJOR）。若重新生成后变体布局变化 → 使用了非确定性随机（MAJOR，应基于 CPos hash）。

### 期望 4: 资源类型筛选独立可控

**操作**: 使用复选框取消勾选某些资源类型，点击「应用筛选」。

**量化标准**:
| 检查项 | 预期值 |
|--------|--------|
| 仅保留 Tiberium | 仅绿色系精灵可见，其他类型 cell 变灰/空 |
| 仅保留 Ore | 仅金色系精灵可见 |
| 全部启用 | 四种颜色同时可见，无类型颜色混合 |
| 类型分布模式 | 每列一种类型的循环模式保持稳定 |

**失败判定**: 若取消某类型后该类型精灵仍然可见 → 筛选逻辑错误（MAJOR）。

### 期望 5: 密度模式切换即时响应

**操作**: 切换密度分布模式（渐变 / 条纹 / 随机 / 热点），点击「重新生成地图」。

**量化标准**:
| 模式 | 视觉特征 |
|------|----------|
| 渐变 | 精灵从左到右尺寸/亮度递增 |
| 条纹 | 精灵从上到下尺寸/亮度逐行递增 |
| 随机 | 密度随机分布，无明显规律 |
| 热点 | 中央区域精灵大且亮，边缘小且暗 |
| 切换延迟 | < 500ms 完成 216 个 cell 的刷新 |

**失败判定**: 若切换模式后视觉无变化 → 模式切换未生效（MAJOR）。若切换耗时 > 2s → 性能退化（MAJOR）。

## 检验流程

### 准备工作

1. 打开测试页面：`http://localhost:5173/test/resource/rendering/`
2. 确认环境信息栏显示 `Babylon.js` + `WebGL 2.0`
3. 默认状态：
   - 18x12 网格，216 个 cell
   - 四种资源类型可见（Tiberium/Ore/Spice/Gems）
   - 条纹密度模式，最大密度 10，3 变体
4. 确认看到彩色网格（绿/金/橙/紫）覆盖在深色底板之上

### 步骤一：精灵位置验证

1. 观察网格整体布局：
   - 精灵应排列成规整的 18x12 矩形
   - 每行 18 个精灵，间距均匀
2. 用鼠标滚轮缩放：
   - 放大时精灵尺寸增大但仍保持间距
   - 缩小时精灵变小但不消失
3. 按住鼠标拖拽平移：
   - 精灵跟随移动，无残影或撕裂
4. 确认空/半空 cell 处能看到底下的地形底板

**预期**: 符合期望 1 → 继续

### 步骤二：密度渐变验证

1. 确认默认「条纹」模式下：
   - 顶部行（第 0-1 行）精灵：尺寸小、颜色暗
   - 中间行（第 5-6 行）精灵：尺寸中等、颜色适中
   - 底部行（第 10-11 行）精灵：尺寸大、颜色亮
2. 用鼠标悬停在某个 cell 上：
   - 工具提示显示 cell 坐标、类型、密度值、帧索引
   - 第 0 行应显示密度=2，帧=0-1
   - 第 11 行应显示密度≈10，帧=7
3. 切换到「渐变」模式 → 「重新生成地图」：
   - 现在从左到右密度递增
4. 切换到「热点」模式 → 「重新生成地图」：
   - 中央区域精灵明显大于边缘

**预期**: 符合期望 2 → 继续

### 步骤三：变体验证

1. 点击「高亮变体边界」按钮：
   - 部分 cell 变为白色 — 这些是不同变体相邻的边界
   - 白色 cell 应形成不规则的区块边界
2. 将变体数改为「1 (无变体)」→ 观察：
   - 所有白色边界消失（所有同类 cell 使用相同变体）
3. 将变体数改为「5」→ 「重新生成地图」→ 「高亮变体边界」：
   - 白色边界增多，区块变小
4. 记录某几个 cell 的变体索引（悬停查看）
   - 重复点击「重新生成地图」确认同一 cell 的变体索引不变（确定性 hash）

**预期**: 符合期望 3 → 继续

### 步骤四：资源类型筛选

1. 取消勾选 Ore、Spice、Gems，仅保留 Tiberium → 「应用筛选」：
   - 仅绿色系精灵可见
   - 其他 cell 变为淡灰色半透明
2. 仅保留 Ore → 「应用筛选」：
   - 仅金色系精灵可见
3. 仅保留 Spice → 「应用筛选」：
   - 仅橙红系精灵可见（Dune 风格）
4. 全部重新勾选 → 「应用筛选」：
   - 四种颜色恢复

**预期**: 符合期望 4 → 继续

### 步骤五：密度模式切换

1. 最大密度改为「6 (低)」→ 「重新生成地图」：
   - 整体密度范围缩小，高低密度 contrast 降低
   - 悬停某 cell 确认密度最大值 = 6
2. 最大密度改为「15 (高)」→ 「重新生成地图」：
   - 低密度 cell 更暗，高密度 cell 非常亮
3. 恢复到默认设置（最大密度 10，条纹）

**预期**: 符合期望 5 → 继续

### 边界/异常测试

1. **边缘 cell**：观察网格四边的 cell，确认密度显著低于内部（模拟矿脉边缘衰减）
2. **快速切换**：快速连续切换 5 次密度模式 → 无崩溃、帧率不下降
3. **全部取消勾选**：尝试取消所有资源类型 → 系统应至少保留一个类型
4. **缩放极限**：滚轮缩放到最远 → 精灵可见，不减出
5. **浏览器窗口调整**：缩小到 800x600 → 布局正常
