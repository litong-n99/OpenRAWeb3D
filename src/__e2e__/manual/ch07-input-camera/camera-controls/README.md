## 期望结果 (Expected Results)

### E1. 坐标系方向 (Coordinate System Orientation)

**上下文**: Babylon.js 使用左手坐标系 (LH)。`ArcRotateCamera.alpha = -PI/2` 将相机置于 -Z 侧，确保屏幕右方向 = 世界 +X 方向。错误的 alpha 值会导致屏幕左右翻转，使所有鼠标交互产生镜像控制。

| # | 期望行为 | 量化指标 |
|---|---------|---------|
| E1.1 | 红色标记 (WPos 5120,0,0 = Vector3 5,0,0) 应出现在白色原点标记的**右侧** | 投影到屏幕后，红色标记的 screen.x > 白色标记的 screen.x，差值 > 20px（在 1x 缩放、1920x1080 下） |
| E1.2 | 蓝色标记 (WPos 0,5120,0 = Vector3 0,0,5) 应出现在白色原点标记的**上方**（+Z 远离相机，在倾斜视角中投影到屏幕上方） | 蓝色标记的 screen.y < 白色标记的 screen.y，差值 > 20px |
| E1.3 | 暗红色标记 (WPos -2560,0,0 = Vector3 -2.5,0,0) 应出现在原点**左侧** | 暗红色标记的 screen.x < 白色标记的 screen.x |
| E1.4 | 暗蓝色标记 (WPos 0,-2560,0 = Vector3 0,0,-2.5) 应出现在原点**下方**（-Z 靠近相机，在倾斜视角中投影到屏幕下方） | 暗蓝色标记的 screen.y > 白色标记的 screen.y，差值 > 20px |
| E1.5 | 绿色高度标记 (WPos 0,0,1024 = Vector3 0,2,0) 应**悬浮**在原点上方，通过垂直线连接地面 | 绿色标记的 Vector3.y = 2.0，其正下方的地面投影 = (0,0,0) |

### E2. 缩放到光标精度 (Zoom-to-Cursor Accuracy)

**上下文**: `adjustZoomAt(dz, center)` 必须保持光标下的世界位置不变。这是通过缩放前记录光标处的世界位置，缩放后调整相机目标使相同世界位置保持在光标下来实现的。

| # | 期望行为 | 量化指标 |
|---|---------|---------|
| E2.1 | 在交叉准星（屏幕中心）处缩放时，WPos 漂移应 ≤ ±2 su（子单位） | 使用滑块从 0.5x 缩放到 3.0x，分 5 步进行，交叉准星处的世界位置偏移 ≤ 2 su（0.002 Babylon 单位） |
| E2.2 | 在屏幕任意点用鼠标滚轮缩放时，光标处的 WPos 漂移应 ≤ ±3 su | 将鼠标放在标记上，使用 Ctrl+滚轮缩放到 0.5x 和 3.0x，标记应保持在光标附近 |
| E2.3 | 缩放不应导致相机目标超出地图边界 | 在地图边缘缩放时，相机目标必须保持在 [0, 10] × [0, 10] Babylon 单位范围内 |

### E3. 边缘滚动检测与边界裁剪 (Edge Scroll Detection & Boundary Clamping)

**上下文**: `ViewportControllerWidget` 在鼠标距画布边缘 ≤ 15px 时激活边缘滚动。`Viewport.clampToBounds()` 防止相机目标移出地图边界。

| E3.2 | 鼠标距画布底部边缘 ≤ 15px 时，底部红色边框高亮 | 同上 |
| E3.3 | 鼠标距画布左边缘 ≤ 15px 时，左侧红色边框高亮 | 同上 |
| E3.4 | 鼠标距画布右边缘 ≤ 15px 时，右侧红色边框高亮 | 同上 |
| E3.5 | 地图边界可视化（金色线框）标记了相机裁剪范围。拖拽平移时相机在边界处停止 | 相机 target.x 始终在 [0, 10]，target.z 始终在 [0, 10] |

## 坐标系参考 (Coordinate System Reference)

### 转换链

```
屏幕像素 (screen px)
    ↓ scene.createPickingRay() + terrain plane (y=0) intersection
Babylon.js Vector3 (x, y, z) — 3D 世界空间
    ↓ vector3ToWPos(): x = v.x*1024, y = v.z*1024, z = v.y*512
OpenRA WPos (X, Y, Z) — 游戏世界坐标，1024 子单位/cell
```

### 方向约定

| 方向 | WPos 轴 | Vector3 轴 | 屏幕表现 (alpha=-PI/2, beta=PI/3) |
|------|---------|-----------|----------------------------------|
| 东 | +X | +Vector3.x | 屏幕右侧 |
| 西 | -X | -Vector3.x | 屏幕左侧 |
| 南 | +Y | +Vector3.z | 屏幕上方（远离相机：相机在 -Z 侧朝 +Z 看，远处物体投影到屏幕上方） |
| 北 | -Y | -Vector3.z | 屏幕下方（靠近相机：相机在 -Z 侧，近处物体投影到屏幕下方） |
| 上 | +Z | +Vector3.y | 屏幕上方（Babylon Y-up） |

### 相机参数

| 参数 | 值 | 说明 |
|------|-----|------|
| `alpha` | `-PI/2` (约 -1.571) | 相机在 -Z 侧，确保屏幕右=世界+X |
| `beta` | `PI/3` (约 1.047) | 60° 俯角（从水平面测量） |
| 默认模式 | `ORTHOGRAPHIC_CAMERA` | RTS 传统俯视视角 |
| 缩放方式 | 正射: `orthoTop/Bottom/Left/Right`; 透视: `radius` | |
| 坐标缩放 | WORLD_SCALE=1/1024, HEIGHT_SCALE=1/512 | 匹配 OpenRA 子单位精度 |
