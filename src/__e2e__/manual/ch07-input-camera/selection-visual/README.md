## 期望结果 (Expected Results)

### E1. 单选高亮响应 (Single-Click Selection Highlight)

**上下文**: 鼠标左键单击某个 actor 后，该 actor 应立即显示选中高亮环/轮廓。OpenRA 中选中效果在渲染的下一帧显示，对应 Babylon.js 中高亮 mesh 应在 `scene.render()` 后的同一帧内可见。

| # | 期望行为 | 量化指标 |
|---|---------|---------|
| E1.1 | 点击「陆战队员 A」后，该 actor 上出现金黄色高亮环 (emissive ring)，颜色为 #FFD700 (gold) | 高亮环应在点击后 ≤1 帧内出现（即 ≤16.7ms @ 60fps），视觉上应为「瞬间」出现，无可见延迟 |
| E1.2 | 高亮环的直径应略大于 actor 本体（超出约 20%），位于 actor 脚下（y≈0.05） | 环外径 = actor 半径 × 1.2，环内径 = actor 半径 × 1.05，环厚度 ≈ 0.05 Babylon 单位 |
| E1.3 | 选中另一个 actor（如「坦克 Alpha」）时，前一个 actor 的高亮环立即消失，仅新选中的 actor 保持高亮 | 旧高亮环应在同一帧内消失，屏幕上不应出现两个同时高亮的 actor |
| E1.4 | 被选中的 actor 上方显示一个半透明的绿色边框包围盒 (wireframe bounding box)，颜色 #00FF00 alpha=0.5 | 包围盒尺寸 = actor mesh 的 bounding box，线宽 = 2px（屏幕空间） |

### E2. 拖拽框选 (Rubber-Band Box Selection)

**上下文**: 鼠标左键按下后拖拽，应在屏幕上绘制一个白色虚线矩形 (rubber-band box)，松手时框内的所有 actor 被选中。

| # | 期望行为 | 量化指标 |
|---|---------|---------|
| E2.1 | 拖拽时屏幕上显示白色虚线矩形框，颜色 #FFFFFF，线宽 2px，虚线样式 dash array = [6, 4]（6px 实线段 + 4px 空隙） | 在 1920×1080 分辨率下，dash 段长度应为 6px，间隙 4px，线宽精确为 2px |
| E2.2 | 矩形框从鼠标按下位置持续延伸至当前鼠标位置，拖拽过程中实时更新（≤1 帧延迟） | 矩形跟随鼠标移动无可见滞后，四角坐标为整数像素值 |
| E2.3 | 松手时框内所有符合条件的 actor 同时被选中（均显示高亮环） | 若框内有 3 个 actor，松手后 3 个 actor 均显示高亮环，出现在同一帧 |
| E2.4 | 若拖拽距离 ≤ 4px（deadzone），不触发框选，退化为单击行为 | 在起点 4px 半径内松手时无矩形框，行为同单击 |
| E2.5 | 松手后矩形框立即消失（≤1 帧） | 松手后下一帧屏幕上不再显示矩形框 |

### E3. Shift 组合操作 (Shift Modifier Selection)

**上下文**: 按住 Shift 键时进行选择操作，新选中的 actor 应**添加**到已有选区，不清除原有选区。

| # | 期望行为 | 量化指标 |
|---|---------|---------|
| E3.1 | Shift+单击「陆战队员 B」（当「陆战队员 A」已被选中时），两个 actor 同时显示高亮环 | 两个高亮环同时可见，颜色均为 #FFD700 |
| E3.2 | Shift+拖拽框选新区域时，新区域内 actor 加入现有选区，原有选区保持不变 | 操作前后原有选中的 actor 高亮环不闪烁、不消失，新选中的 actor 追加高亮环 |
| E3.3 | Shift+单击**已选中的 actor**时，该 actor 应从选区中移除（toggle off，高亮环消失） | 移除操作在同一帧内完成，其他选中 actor 不受影响 |
| E3.4 | 左面板「当前选中」列表实时更新（≤100ms），正确反映 Shift 添加/移除操作 | 列表中的 actor ID 与屏幕上的高亮环一一对应 |

### E4. 选中血量条 (Selection Health Bar)

**上下文**: 选中的 actor 上方应显示血量条，血量条高度反映当前 HP 百分比。

| # | 期望行为 | 量化指标 |
|---|---------|---------|
| E4.1 | 满血 (100% HP) 时血量条显示为完整绿色 (#00FF00)，占满整个血量条宽度 | 血量条总宽度 = actor 直径 × 1.5，高度 = 0.08 Babylon 单位，绿色填充 100% |
| E4.2 | 50% HP 时血量条绿色填充部分精确占 50% 宽度，右侧 50% 为深红色 (#8B0000) 背景 | 绿色部分宽度 = 总宽度 × 0.50，容差 ±2% |
| E4.3 | 25% HP 时血量条绿色填充部分占 25%，右侧 75% 为深红色背景 | 绿色部分宽度 = 总宽度 × 0.25，容差 ±2%，血量条颜色可从绿色渐变为黄色 (#FFFF00) 再到红色 (#FF0000) 当 HP < 25% |
| E4.4 | 多个 actor 被选中时，每个 actor 上方均独立显示血量条 | N 个选中 actor = N 个血量条，互不重叠遮挡 |
| E4.5 | 取消选中后血量条立即消失（≤1 帧） | 取消选中后下一帧血量条不可见 |

### E5. 空点击清除选区 (Empty Click Deselect)

**上下文**: 点击地图空白区域（无 actor 处）时，所有当前选区应被清除。

| # | 期望行为 | 量化指标 |
|---|---------|---------|
| E5.1 | 点击场景中的空地（无 actor 区域），所有选中 actor 的高亮环立即消失（≤1 帧） | 点击空地后 ≤16.7ms 内所有高亮环不可见 |
| E5.2 | 空点击后血量条同步消失 | 血量条与高亮环在同一帧内消失 |
| E5.3 | 空点击后左面板「当前选中」列表立即清空（≤50ms） | 列表显示 "(无)" 或为空 |
