Actor IDLE + Pause 阶段: overlay 网格完全隐藏 (isVisible=false)，

播放阶段持续 配置 ticks ±2 ticks

暂停阶段持续 配置 ticks ±2 ticks
(默认 30 ticks = 1.2s @ 25tps)。
E5. Actor 非空闲时 overlay 立即停止

≤2 ticks (≤80ms) 内隐藏。

Overlay 位置 = Body 中心 + 配置的偏移量 (WVec)。
调整 X/Y/Z 滑块后 overlay 实时移动。

当前序列名可通过 test harness 查询，
IDLE 时为 "idle-overlay"。
