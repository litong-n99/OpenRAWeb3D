# Map 地图数据层可视化验证 (Tile / Resource / Height)

**OpenRA 对照**: `Map.ts` (Map class, CellLayer data planes, centerOfCell, contains, coordinate conversion)  
**测试重点**: 地图数据层的创建、填充、读取，CellLayer 索引公式，坐标转换可视化

## 期望结果

### 1. 地图数据层正确生成和可视化

32x32 合成地图包含同心圆模式的真实感地形：

**可量化标准**:
- 地图中心 (16,16) 附近约 7-8 个 cell 为 Water 类型 (蓝色 #4169E1)
- 中心向外第 2 圈（距离 0.25-0.3 归一化半径）为 Clear (淡绿 #90EE90)
- 中圈 (0.3-0.6) 为 Clear + Rough 混合 (淡绿/棕褐交替)
- 外圈 (0.6-0.8) 为 Rock 类型 (灰色 #808080)，height >= 1
- 切换为 "Tile 层" 视图时，各颜色区域边界清晰，形成明显的同心圆图案
- 切换为 "Resource 层" 视图时，Tiberium 资源点以绿色亮点分布在环形区域中
- 总 cell 数 = 32 x 32 = 1024，3D 场景中可见 1024 个面片，无缺失或重叠

### 2. 视图切换和高度缩放交互

四种视图模式可以独立切换，视觉呈现立即更新：

**可量化标准**:
- 点击 "Tile 层" 按钮后，场景在 100ms 内切换为按地形类型着色的视图
- 点击 "Resource 层" 后，只有含资源的 cell 显示为亮绿色 (#00E07F)，无资源 cell 为深灰色
- 点击 "Height 层" 后，cell 颜色由高度决定: H=0 暗绿, H=1 棕色, H=2 浅灰
- 拖动 "高度缩放" 滑杆从 0.2x 到 5.0x，cell 的 Y 轴高度实时变化，在 16ms 内响应
- 四个视图按钮中，当前选中的按钮显示高亮边框（红色 #e94560），未选中的为正常样式

### 3. Cell 坐标信息准确

点击任意 cell 后，右侧面板显示正确的坐标信息：

**可量化标准**:
- 点击地图中心附近 cell (CPos 约为 (16,16))，面板显示 MPos = (16,16)
- 对于 Rectangular 网格，centerOfCell 返回的 WPos 满足: X = 1024*CPos.X + 512, Y = 1024*CPos.Y + 512
- 面板中 "Tile" 字段显示地形类型名称（如 "Clear", "Water"）
- "Resource" 字段显示资源类型和密度（如 "type=1, density=5"，或无资源时 "type=0, density=0"）
- "Height" 和 "Ramp" 字段显示正确的数值

### 4. 地图重建与随机种子

**可量化标准**:
- 修改 "随机种子" 输入框为不同值后点击 "重新生成"，地图布局发生变化但模式一致（仍为同心圆）
- 使用相同种子 (如 42) 生成的地图与之前完全一致（确定性）
- 修改地图尺寸为 "16x16" 或 "64x64" 后重建，cell 数量正确变化
- 16x16 重建在 500ms 内完成，64x64 重建在 2000ms 内完成

### 5. 渲染性能

**可量化标准**:
- 32x32 = 1024 个 cell 渲染时 FPS 稳定在 55-60
- 64x64 = 4096 个 cell 渲染时 FPS 不低于 30
- 摄像机旋转/缩放时无明显卡顿
- 视图切换后 GPU 内存不持续增长（无泄漏）

## 检验流程

### 准备工作

1. 打开测试页面: `http://localhost:5173/test/map/map-data-viewer/`
2. 确认环境信息栏显示 "WebGL 2.0" 引擎，网格显示 "32x32 Rectangular"
3. 设置屏幕分辨率为 1920x1080 (1x 缩放)

### 步骤一: 验证 Tile 层视图

1. 确认 "Tile 层" 按钮为选中状态（红色高亮）
2. 观察 3D 场景中的地形网格，应看到明显的同心圆图案:
   - 中心蓝色区域 (Water) → 淡绿环 (Clear/Beach) → 绿/棕混合环 (Clear/Rough) → 灰色外环 (Rock)
3. 旋转摄像机到俯视角度，确认同心圆形状完整对称
4. 旋转到侧面角度，确认平面 cell 在同一高度
5. 预期: 地形图案清晰，颜色与图例一致

### 步骤二: 验证 Resource 层视图

1. 点击 "Resource 层" 按钮
2. 观察场景变化: 大部分 cell 变为深灰色
3. 确认绿色亮点 (Tiberium) 分布在环形区域中
4. 预期: 资源点分布合理，密度高的点颜色更亮

### 步骤三: 验证 Height 层和缩放

1. 点击 "Height 层" 按钮
2. 观察颜色分布: 中心蓝色区域仍为低地 (暗绿)，外圈为高地 (棕/灰)
3. 将 "高度缩放" 滑杆拖到 5.0x
4. 旋转摄像机到侧面，观察 cell 有明显的高度差
5. 将滑杆拖回 1.0x，确认高度恢复正常
6. 预期: 高度缩放实时生效，视觉上 cell Y 轴变化明显

### 步骤四: 验证 Cell 选中和坐标

1. 点击 3D 场景中心的水面区域 (蓝色 cell)
2. 检查右侧面板:
   - CPos 约 (16, 16)
   - MPos = (16, 16)
   - Tile 显示 "type=3, idx=0 (Water)"
   - Height = 0
3. 点击外圈的灰色 Rock cell
4. 检查: Height >= 1, Ramp = 5, Tile 显示 "Rock"
5. 预期: 坐标转换公式正确，数据层值准确

### 步骤五: 验证重建和种子

1. 将地图尺寸改为 "64x64"，种子改为 "123"
2. 点击 "重新生成"
3. 确认网格变为 64x64 (4096 cells)，FPS 保持 >= 30
4. 将种子改回 "42"，尺寸改回 "32x32"，点击 "重新生成"
5. 确认地图恢复为初始的同心圆图案（与步骤一的形状一致）
6. 预期: 确定性生成，不同种子产生不同但合理的地图
