# 空中攻击 - FlyAttack + FlyAttackRun + StrafeAttackRun 验收测试

**审核状态**: 待审核 (Pending Review)
**创建日期**: 2026-06-16
**对应模块**: `src/OpenRA.Mods.Common/Activities/Air/FlyAttack.ts`

## 期望结果 (Expected Results)

1. **Default 攻击 (FlyAttackRun)**:
   - 飞机接近目标，掠过射击，飞出射程外，再次进入。
   - 可量化指标: 攻击范围 = `2500 WDist`，最小射程 = `500 WDist`。
   - 可量化指标: 每次攻击运行约 `20-30 ticks`。
   - 可量化指标: 弹药每次攻击消耗 `~0.5%/tick`。
   - 可量化指标: 目标线颜色 = `#FF0000` (红色)。

2. **Strafe 扫射 (StrafeAttackRun)**:
   - 飞机直线穿过目标区域，持续射击。
   - 可量化指标: 退出射程 = `2000 WDist`。
   - 可量化指标: 扫射持续时间约 `40 ticks`。
   - 可量化指标: 弹药消耗 `~1%/tick` (更快)。
   - 可量化指标: 飞行轨迹为直线穿过目标。

3. **Hover 悬停攻击**:
   - 飞机悬停在射程内，转向目标射击。
   - 可量化指标: 悬停距离 = `~750 WDist` (攻击范围的 30%)。
   - 可量化指标: 转向速度 = `32 WAngle/tick`。
   - 可量化指标: 当 facing 与目标方向偏差 `< 64 WAngle` 时开火。
   - 可量化指标: 弹药消耗 `~0.3%/tick` (较慢但持续)。

4. **弹药耗尽返航 (ReturnToBase)**:
   - 弹药耗尽后触发返航，绿色目标线指向基地。
   - 可量化指标: 目标线颜色变为 `#00FF00` (绿色)。
   - 可量化指标: 到达基地 (`< 500 WDist`) 后弹药补满至 100%。
   - 可量化指标: 返航速度 = 正常速度。

5. **开火效果**:
   - 可量化指标: 机头前方出现黄色光球 (`#FFCC33`)，持续 `5 ticks`。
   - 可量化指标: 开火位置 = 机头前方 `1.0` 世界单位。

## 检验流程

### 1. 准备工作

- 打开测试页面: `http://localhost:5173/test/activities/fly-attack/`
- 确认环境信息栏显示 "引擎: WebGL 2.0"
- 设置屏幕分辨率为 1920×1080 (1x 缩放)
- 确认页面显示: 红色攻击机、蓝色目标建筑、绿色基地、红色射程圈

### 2. 步骤一: Default 攻击 (掠过攻击)

- 操作: 选择攻击类型为 "Default (掠过攻击)"
- 操作: 点击 "攻击目标" 按钮
- 观察点:
  - 攻击机从左侧飞向目标
  - 接近目标后出现黄色开火闪光
  - 飞过目标后飞出射程外
  - 再次转向目标进行第二次攻击
  - 红色目标线连接攻击机与目标
  - 状态栏显示 "attack_run"
- 预期: ✅ 攻击机掠过目标射击，进行多次攻击运行

### 3. 步骤二: Strafe 扫射

- 操作: 点击 "重置"
- 操作: 选择攻击类型为 "Strafe (扫射)"
- 操作: 点击 "攻击目标"
- 观察点:
  - 攻击机直线飞向目标
  - 穿过目标区域时持续开火 (黄色闪光频繁)
  - 飞出 `2000 WDist` 后退出
  - 弹药消耗更快 (状态栏显示百分比下降更快)
  - 飞行轨迹为直线穿过目标
- 预期: ✅ 直线扫射，持续开火，快速退出

### 4. 步骤三: Hover 悬停攻击

- 操作: 点击 "重置"
- 操作: 选择攻击类型为 "Hover (悬停攻击)"
- 操作: 点击 "攻击目标"
- 观察点:
  - 攻击机接近目标后悬停
  - 转向目标方向 (facing 调整)
  - 对准后开火
  - 保持位置持续攻击约 60 ticks
  - 弹药消耗较慢
- 预期: ✅ 悬停转向，对准后开火

### 5. 步骤四: 弹药耗尽返航

- 操作: 点击 "重置"，选择 "Default"，点击 "攻击目标"
- 操作: 等待弹药降至 0% (或点击 "模拟弹药耗尽")
- 观察点:
  - 弹药耗尽后攻击机停止攻击
  - 目标线变为绿色 (指向绿色基地)
  - 状态变为 "return_to_base"
  - 攻击机飞向基地
  - 到达基地后弹药恢复 100%
  - 状态变为 "idle"
- 预期: ✅ 弹药耗尽后自动返航，绿色目标线，补满弹药

### 6. 步骤五: 切换目标位置

- 操作: 点击画布上的新位置设置目标
- 操作: 点击 "攻击目标"
- 观察点:
  - 蓝色目标建筑移动到新位置
  - 红色射程圈跟随移动
  - 攻击机飞向新目标
- 预期: ✅ 目标位置可动态更改

### 7. 边界/异常测试

- **边界 A - 目标在射程外**: 设置目标很远 (> 4000 WDist)
  - 预期: ✅ 攻击机接近目标，进入射程后攻击

- **边界 B - 快速重置**: 攻击中点击 "重置"
  - 预期: ✅ 攻击机立即回到起点，清除所有轨迹和效果

- **边界 C - 弹药耗尽后再次攻击**: 返航补满后再次攻击
  - 预期: ✅ 弹药恢复 100%，可再次执行攻击
