## 期望结果 (Expected Results)

1. **CircleRanges 渲染正确半径**: 以目标点为圆心，按照 WDist 配置的半径值在 Canvas 上绘制彩色圆圈。
   - 可量化指标: WDist=2048 (2 cells) 在 14-cell 网格上渲染半径 = gridWidth/14 * 2 = ~14.3% 网格宽度
   - 可量化指标: WDist=4096 (4 cells) ~28.6% 网格宽度
   - 可量化指标: WDist=6144 (6 cells) ~42.9% 网格宽度
   - 可量化指标: 圆形必须正圆 (aspect ratio 1:1, 不因窗口缩放变形)

2. **CircleColor (填充色)** 与配置一致:
   - 默认: 半透明红色 `rgba(255, 0, 0, 0.50)` (OpenRA: Color.FromArgb(128, Color.Red))
   - 可量化指标: 填充 Alpha = 颜色选择器 Alpha 滑块值 / 255。滑块=128 → alpha=0.50
   - 可量化指标: 改变填充色 → 所有圆圈填充色同步更新

3. **CircleBorderColor (边框色)** 与配置一致:
   - 默认: `rgba(255, 0, 0, 0.25)` (OpenRA: Color.FromArgb(64, Color.Red))
   - 可量化指标: 边框色 Alpha 固定为 64/255 ≈ 0.25 (OpenRA 默认值)
   - 可量化指标: 边框线绘制在填充色之上，视觉上更淡

4. **CircleWidth / CircleBorderWidth 独立可调**:
   - CircleWidth (线宽) 默认 = 1px (薄内线)
   - CircleBorderWidth (边框宽) 默认 = 3px (粗外边框)
   - 可量化指标: 线宽滑块 1-6 → 内线像素宽度变化
   - 可量化指标: 边框宽滑块 1-8 → 外边框像素宽度变化

5. **多圈重叠渲染**: 多个 CircleRanges 同时渲染，填充色 alpha 叠加产生同心圆视觉层次。预设 "Concentric (5 rings)" 应显示 5 个嵌套同心圆。
