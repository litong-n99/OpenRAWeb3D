期望结果 (Expected Results)

  • 状态机: 沙虫在 7 个状态间切换: Burrowed (地下, 不可见)、Wandering (随机移动)、MovingToNoise (追踪噪声)、Emerging (出地, Y轴上升)、Attacking (吞食目标, 目标缩小消失)、Submerging (下潜, Y轴下降)、Disappear (缩放消失)。核心可视状态为前 4 种。
  • 地下移动: 沙虫在地下时 Y < 0 且半透明 (alpha < 0.3)，按 WAngle 朝向移动。WAngle 0 = 北(负Z), 逆时针递增。
  • 出地动画: 沙虫从 Y < 0 上升到 Y > 0，持续约 AttackDelay 30 ticks (约 1.2 秒 @ 25fps)。
  • 吞食动画: 目标单位从正常大小缩放到 scale = 0，持续约 ReturnDelay 60 ticks (约 2.4 秒 @ 25fps)。
  • 噪声追踪: 沙虫通过 AttractsWorms 噪声源追踪目标。噪声强度可视化径向圆圈，沙虫向噪声向量方向移动。
  • 消失概率: 攻击后 ChanceToDisappear (默认 100%) 决定沙虫是否消失。消失时播放缩小+淡出动画。
  • 近距离攻击: 目标在 IgnoreNoiseAttackRange (3 cells) 内时，无视噪声直接攻击。
