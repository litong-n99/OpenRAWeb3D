# 沙虫系统 - 地下移动 + 出地 + 吞食攻击 验收测试

**审核状态**: 审核中 (R1 Review → NEEDS FIXES → R2)
**创建日期**: 2026-06-17
**对应模块**: `src/OpenRA.Mods.D2k/Traits/Sandworm.ts`, `src/OpenRA.Mods.D2k/Activities/SwallowActor.ts`, `src/OpenRA.Mods.D2k/Traits/AttackSwallow.ts`

## 期望结果 (Expected Results)

1. **状态机转换**:
   - 沙虫有 7 个状态: Burrowed (地下)、Emerging (出地中)、Attacking (吞食中)、Submerging (下潜中)、Wandering (随机移动)、MovingToNoise (追踪噪声)、以及消失 (Disappear) 时的缩放动画。核心可视状态为前 4 种。
   - 可量化指标: Burrowed 状态沙虫 Y 坐标 < -2.0 且 alpha < 0.3 (半透明不可见)。
   - 可量化指标: Emerging 状态沙虫 Y 从 -2.0 线性上升到 +1.5，持续 AttackDelay 30 ticks (约 1.2 秒 @ 25 tick/s)。
   - 可量化指标: Attacking 状态沙虫 Y = +1.5，目标单位 scale 从 1.0 缩小到 0.0，持续 ReturnDelay 60 ticks (约 2.4 秒)。
   - 可量化指标: Submerging 状态沙虫 Y 从 +1.5 线性下降到 -2.0，持续约 30 ticks。

2. **地下移动与朝向**:
   - 可量化指标: 沙虫在地下时沿 WAngle 方向移动，WAngle 0 = 北 (负 Z)，逆时针递增。256 = 东 (+X)，512 = 南 (+Z)，768 = 西 (-X)。
   - 可量化指标: 每 tick 移动速度 = 80 WDist (约 0.078 世界单位)，移动轨迹为均匀的直线。
   - 可量化指标: 地下移动半径可调 (WanderMoveRadius)，默认 5 cells (DEFAULT_SEARCH_RADIUS)。可通过滑块在 1-20 cells 范围调节。

3. **噪声追踪**:
   - 可量化指标: 噪声源 (桃色球体) 向沙虫发射径向脉冲，脉冲频率 = 每 25 ticks 一次。沙虫 state 切换到 "MovingToNoise" 并向噪声向量方向移动。
   - 可量化指标: 多个噪声源时，噪声向量为所有 AttractsWorms.attractionAtPosition() 结果的矢量和。
   - 可量化指标: MaxSearchRadius 默认 20 cells (圆半径)，超出此范围的噪声源不产生影响。

4. **近距离攻击 (IgnoreNoiseAttackRange)**:
   - 可量化指标: 当目标进入 3 cells 范围 (IgnoreNoiseAttackRange 默认值) 时，沙虫跳过噪声检测，直接发起吞食攻击。
   - 可量化指标: 目标圆环从蓝色 (搜索范围) 变为红色 (攻击范围)，触发 "Close-Range Attack" 标签。

5. **吞食动画**:
   - 可量化指标: 目标单位开始吞食后 scale 从 1.0 → 0.0 线性缩小，Y 坐标从 0 → +1.5 (被吸入沙虫口中)。
   - 可量化指标: 吞食完成后目标消失 (disposed)，沙虫自动进入 Submerging 状态。

6. **消失概率 (ChanceToDisappear)**:
   - 可量化指标: 攻击完成后，沙虫有 ChanceToDisappear% (默认 100%) 概率消失。
   - 可量化指标: 消失动画: scale 从 1.0 → 0.0 + alpha 从 1.0 → 0.0，持续约 20 ticks (0.8 秒)。

7. **状态标识颜色**:
   - Burrowed: 沙虫颜色 = 半透明棕色 `rgba(139, 90, 43, 0.2)`
   - Emerging: 沙虫颜色 = 棕色 `#8B5A2B` 逐渐不透明
   - Attacking: 沙虫颜色 = 深红色 `#8B0000`
   - Submerging: 沙虫颜色 = 棕色逐渐变为半透明

## 检验流程

### 1. 准备工作

- 打开测试页面: `http://localhost:5173/test/ch19-d2k/sandworm/`
- 确认环境信息栏显示 "引擎: WebGL 2.0"
- 设置屏幕分辨率为 1920x1080 (1x 缩放)
- 确认页面显示沙漠色地形网格和棕色沙虫半透明模型 (地下状态)

### 2. 步骤一: 地下移动 + 噪声追踪

- 操作: 点击 "生成噪声源" 按钮，在地图上生成 2-4 个噪声源
- 操作: 点击 "触发目标扫描"
- 观察点:
  - 沙虫开始向噪声向量方向移动 (地下，半透明)
  - 噪声源向沙虫方向发射径向脉冲
  - 状态栏显示 "MovingToNoise"
- 预期: ✅ 沙虫沿噪声向量方向移动，WAngle 朝向朝向噪声源方向

### 3. 步骤二: 出地动画

- 操作: 点击 "强制出地" 按钮
- 观察点:
  - 沙虫 Y 坐标从 -2.0 上升到 +1.5
  - 沙虫 alpha 从 0.2 变为 1.0 (完全不透明)
  - 状态栏显示 "Emerging"，计数倒计时
  - 地面出现 "波纹" 效果 (圆环扩散)
- 预期: ✅ 沙虫在 ~30 ticks 内从地下上升到地面，颜色从不透明棕色变为完全不透明的深棕色

### 4. 步骤三: 吞食攻击

- 操作: 点击 "发起吞食攻击" 按钮 (选择一个目标)
- 观察点:
  - 沙虫向目标方向移动
  - 目标单位开始缩小 (scale 1.0 → 0.0)
  - 目标单位 Y 坐标上升 (被吸入)
  - 状态栏显示 "Attacking"，攻击倒计时
- 预期: ✅ 目标在 ~60 ticks 内缩小消失，沙虫颜色变为深红色

### 5. 步骤四: 下潜 + 消失

- 操作: 吞食完成后自动触发，或点击 "强制下潜"
- 观察点:
  - 沙虫 Y 坐标从 +1.5 下降到 -2.0
  - 沙虫 alpha 从 1.0 变为 0.2
  - 如果触发消失: 沙虫同时缩小 + 淡出
- 预期: ✅ 沙虫在 ~30 ticks 内回到地下状态

### 6. 边界/异常测试

- **边界 A - 近距离攻击**: 将目标移动到沙虫 3 cells 范围内
  - 预期: ✅ 状态栏显示 "Close-Range Attack"，跳过噪声检测直接攻击

- **边界 B - 移动半径调节**: 调节移动半径滑块到 20
  - 预期: ✅ 沙虫扫描范围圆环半径扩大

- **边界 C - 无噪声源时扫描**: 清除所有噪声源后点击扫描
  - 预期: ✅ 沙虫随机选择一个方向移动 (wander)，状态栏显示 "Wandering"

- **边界 D - 重置**: 任何状态下点击 "重置"
  - 预期: ✅ 所有状态恢复到初始值，沙虫位置回到原点
