---

## 测试目标

本测试页面验证 Player 系统的关键视觉行为：

1. Player 原始颜色 (ARGB) 在 3D 渲染中的正确显示
2. PlayerRelationshipColor 的 4 种关系色映射 (Self/Ally/Neutral/Enemy)
3. 外交关系矩阵驱动的关系色切换
4. 视角切换：不同观察者看到的关系色应不同

---

## B. 期望结果（可量化验收标准）

### 期望 1: Player 原始颜色 ARGB → 3D 渲染正确

**操作**: 取消勾选「启用关系颜色」，观察所有 Player 单位。

**量化标准**:
| Player | ARGB 原始色 | 期望 3D 颜色 (RGB) | 色差容限 |
|--------|------------|-------------------|---------|
| Player A | `0xFF3399F2` | R≈51, G≈153, B≈242 | deltaE < 5 |
| Player B | `0xFFF25433` | R≈242, G≈84, B≈51 | deltaE < 5 |
| Player C | `0xFF33CC66` | R≈51, G≈204, B≈102 | deltaE < 5 |
| Player D | `0xFFFF9933` | R≈255, G≈153, B≈51 | deltaE < 5 |
| Neutral | `0xFFB0B0B0` | R≈176, G≈176, B≈176 | deltaE < 5 |

**失败判定**: 任何颜色肉眼明显偏差（deltaE > 10）→ **MAJOR** ARGB 解析错误

### 期望 2: 关系色映射正确（4 种 stance color）

**操作**: 启用「启用关系颜色」，以 Player A 为观察者。

**量化标准**:
| 目标 Player | 预期关系 | 关系色 (ARGB) | 期望 3D 颜色 |
|------------|---------|--------------|-------------|
| Player A (自己) | **Self** | `0xFF00FF00` | 绿色 (0,255,0) |
| Player B | **Enemy** (默认) | `0xFFFF0000` | 红色 (255,0,0) |
| Player C | **Ally** (默认) | `0xFFFFFF00` | 黄色 (255,255,0) |
| Player D | **Neutral** (默认) | `0xFFFFFFFF` | 白色 (255,255,255) |
| Neutral | **Neutral** | `0xFFFFFFFF` | 白色 (255,255,255) |

**对应 OpenRA 源码常量**:
- `STANCE_COLOR_SELF = 0xFF00FF00`
- `STANCE_COLOR_ALLIES = 0xFFFFFF00`
- `STANCE_COLOR_NEUTRALS = 0xFFFFFFFF`
- `STANCE_COLOR_ENEMIES = 0xFFFF0000`

**失败判定**: 关系色与期望不符 → **BLOCKER** PlayerRelationshipColor 逻辑错误

### 期望 3: 切换观察者视角后关系色正确变化

**操作**: 点击「切换观察者视角」按钮，视角从 A → B → C → D → N。

**量化标准**:
- 切换为 Player B 观察者时，Player A 应变为 Enemy 色（红色），Player D 应变为 Ally 色（黄色）
- 切换为 Neutral 观察者时，所有其他 Player 应显示为 Neutral 色（白色）
- 每个视角切换后，右侧颜色面板的「显示」色条和「关系」标签同步更新
- 关系方向箭头线（彩色曲线）随观察者变化重新绘制

**失败判定**: 视角切换后颜色不正确 → **MAJOR** RelationshipWith 逻辑错误

### 期望 4: 关系色禁用时恢复原始色

**操作**: 取消勾选「启用关系颜色」。

**量化标准**:
- 所有 Player 单位恢复原始 ARGB 颜色
- 右侧颜色面板「关系」一栏显示 "关系色禁用 — 使用原始色"
- 5 个 Player 的单位颜色互不相同，与期望 1 中的原始色一致

**失败判定**: 恢复原始色后有颜色与实际 ARGB 不符 → **MINOR** 开关逻辑错误

### 期望 5: 随机外交关系功能正常

**操作**: 点击「随机外交关系」按钮多次 (5+ 次)。

**量化标准**:
- 每次点击后关系矩阵立即更新（关系网格中的单元格标签变化）
- 场景中的单位颜色随关系变化立即更新
- Self 关系永远不变（对角线始终为 "Self"）
- 每种关系 (Ally/Neutral/Enemy) 在多次随机后都有出现

**失败判定**: 矩阵更新后场景颜色不一致 → **MAJOR** 数据-视图同步错误

### 期望 6: 颜色面板信息完整性

**操作**: 观察右侧颜色面板。

**量化标准**:
- 每个 Player 显示: 名称、阵营、原始 ARGB、当前显示 ARGB、换算后的十六进制色值、当前关系
- 左侧色块 (`swatch`) 的 `background-color` CSS 与 ARGB 换算的十六进制一致
- 外交关系矩阵网格中，当前观察者的行以 `▶` 标记

**失败判定**: 面板显示信息与实际状态不一致 → **MINOR** UI 数据绑定错误

## 检验流程

### 准备工作

1. 打开测试页面：`http://localhost:5173/test/player/player-diplomacy/`
2. 确认页面分为左侧 3D 场景 + 右侧颜色面板
3. 确认环境信息栏显示 WebGL 2.0

### 步骤一：原始色验证

1. 取消勾选「启用关系颜色」
2. 比较场景中 5 个 Player 的单位颜色与期望 1 中的表格
3. 放大观察个别单位 → 确认颜色正确

**预期**: ✅ 符合期望 1

### 步骤二：关系色验证 (Player A 视角)

1. 确保观察者 = Player A
2. 勾选「启用关系颜色」
3. 验证 Player A 自身为绿色 → ✅ Self 色
4. 验证 Player B 为红色 → ✅ Enemy 色
5. 验证 Player C 为黄色 → ✅ Ally 色
6. 验证 Player D 为白色 → ✅ Neutral 色

**预期**: ✅ 符合期望 2

### 步骤三：视角切换测试

1. 点击「切换观察者视角」到 Player B
2. 验证 Player A 变为红色 (Enemy) → ✅
3. 点击到 Player C → 颜色重新排列
4. 遍历所有 5 个视角

**预期**: ✅ 符合期望 3

### 步骤四：关系色禁用

1. 取消勾选「启用关系颜色」
2. 验证所有单位恢复原始色

**预期**: ✅ 符合期望 4

### 步骤五：随机外交关系

1. 点击「随机外交关系」5 次
2. 每次验证矩阵更新 + 场景颜色更新同步

**预期**: ✅ 符合期望 5

### 步骤六：面板信息验证

1. 逐个检查每个 Player 的 ARGB 值、显示色、关系
2. 对比左侧色块与期望颜色

**预期**: ✅ 符合期望 6

### 边界/异常测试

1. **快速连续切换视角**: 连点 10 次 → 无崩溃, 无状态残留
2. **重置**: 点击「重置」→ 恢复初始状态 (Player A 视角, 启用关系色)
3. **窗口缩放**: 缩小窗口到 800x600 → 颜色面板可滚动, 3D 场景正常渲染
