## 期望结果 (Expected Results)

1. **三态可见性渲染**: 三种遮挡状态在 3D 场景中清晰可辨，颜色与透明度严格符合规格。
   - Hidden (0): `rgba(0, 0, 0, 1.0)` -- 完全不透明黑色，下方绿色地形完全不可见
   - Explored (1): `rgba(18, 20, 32, 0.55)` -- 半透明暗蓝灰色（战争迷雾），绿色地形隐约可见但明显变暗
   - Visible (2): `alpha = 0` -- 完全透明，下方绿色地形清晰可见 (`#2d5a1e` 草绿色)
   - 可量化指标: 在 512x512 纹理分辨率下，每个 Cell 为 32x32 像素，颜色必须均匀无噪点

2. **边缘混合 (Edge Blending)**: 相邻 Cell 状态不同时，边界处渲染 4px 渐变过渡条带。
   - 渐变宽度: 4 像素 (Canvas2D `createLinearGradient`)
   - 渐变方向: 水平边界为水平渐变，垂直边界为垂直渐变
   - 可量化指标: 同状态相邻 Cell 之间**无渐变线**（边界不可见）；不同状态相邻 Cell 之间**有渐变线**（4px 宽条带）
   - 可量化指标: Hidden↔Explored 边界渐变从 `rgba(0,0,0,1)` 到 `rgba(18,20,32,0.55)`
   - 可量化指标: Explored↔Visible 边界渐变从 `rgba(18,20,32,0.55)` 到 `rgba(0,0,0,0)`
   - 可量化指标: Hidden↔Visible 直接边界渐变从 `rgba(0,0,0,1)` 到 `rgba(0,0,0,0)`

3. **3D 空间定位 (3D Positioning)**: 覆盖层平面在 3D 空间中正确位于地形上方。
   - 可量化指标: 覆盖层 Y=0.0，地形 Y=-0.005，间距 0.005 世界单位防止 Z-fighting
   - 可量化指标: 旋转摄像机到任意角度（alpha 0-360, beta 5-85 度），覆盖层始终紧贴地形表面，无漂浮或穿透
   - 可量化指标: 正上方俯视时（beta < 10 度），纹理正常显示无透视摩尔纹

4. **动态更新性能**: 点击/拖拽改变 Cell 状态时，覆盖纹理即时重绘。
   - 可量化指标: 单次 Canvas2D 重绘延迟 < 50ms（256 个 Cell + ~480 边缘检查 + 渐变绘制），人眼感知为即时更新
   - 可量化指标: 连续拖拽时 FPS 稳定在 55-60，无帧率突降或画面撕裂
   - 可量化指标: 无闪烁（上一帧残留消失）、无残影（旧状态不留痕迹）

5. **状态统计精确性**: 右侧面板实时显示三种状态的 Cell 数量。
   - 可量化指标: Hidden + Explored + Visible = 256（16x16 网格总和不变）
   - 可量化指标: 全部 Hidden (Reset) → Hidden=256, Explored=0, Visible=0
   - 可量化指标: 全部 Visible → Hidden=0, Explored=0, Visible=256
   - 可量化指标: 全部 Explored → Hidden=0, Explored=256, Visible=0

6. **批量操作正确性**: 预设按钮正确影响所有 256 个格子。
   - "全部揭示": 覆盖层完全透明消失，256 格绿色地形全部可见
   - "全部探索": 覆盖层变为均匀半透明暗蓝灰色，256 格全部被滤镜覆盖
   - "全部隐藏 (Reset)": 覆盖层恢复完全不透明黑色，256 格全部隐藏
   - "圆形揭示": 中心圆形可见区域 (半径 5)，中间探索环 (半径 3)，外围隐藏 — 三态同时呈现

## 检验流程

### 1. 准备工作

- 打开测试页面: `http://localhost:5173/test/ch25-shroud/shroud-overlay/`
- 确认右侧面板引擎信息显示 **"WebGL 2.0"**
- 设置屏幕分辨率为 1920x1080 (1x 缩放)
- 确认页面加载后网格全部为黑色 (Hidden 状态)，绿色地形完全不可见
- 确认右侧面板状态统计: Hidden=256, Explored=0, Visible=0

### 2. 步骤一: 三态可见性逐一验证

- 操作: 点击右侧 "全部揭示" 按钮
- 观察点:
  - 黑色覆盖层完全消失
  - 露出完整的绿色地形网格 (16x16 格，草绿色 `#2d5a1e`，带深绿网格线)
  - 右侧面板: Hidden=0, Explored=0, Visible=256
- 预期: ✅ 黑色完全消除，256 格绿色地形清晰可辨

- 操作: 点击右侧 "全部探索" 按钮
- 观察点:
  - 覆盖层变为半透明暗蓝灰色 (`rgba(18,20,32,0.55)`)
  - 绿色地形可见但被暗蓝灰色滤镜覆盖，亮度明显降低
  - 右侧面板: Hidden=0, Explored=256, Visible=0
- 预期: ✅ 暗蓝灰色均匀覆盖，无局部颜色异常或噪点

- 操作: 点击右侧 "全部隐藏 (Reset)" 按钮
- 观察点:
  - 覆盖层变为完全不透明黑色
  - 绿色地形完全不可见
  - 右侧面板: Hidden=256, Explored=0, Visible=0
- 预期: ✅ 纯黑覆盖，地形完全不可见，无漏光

### 3. 步骤二: 圆形揭示模式验证

- 操作: 点击 "圆形揭示 (三态同心圆)" 预设按钮
- 观察点:
  - 场景中心出现圆形可见区域 (半径 5 格, 中心坐标 8,8)
  - 可见区域外是暗蓝灰色探索环 (半径 3 格)
  - 最外层是黑色隐藏区域 (角落区域)
  - 三个状态形成同心圆状分布
- 预期: ✅ 三态同时呈现，边界清晰，渐变过渡条带在 Hidden↔Explored 和 Explored↔Visible 边界处可见

### 4. 步骤三: 画笔交互验证

- 操作: 确认绘制模式为 "揭示 (=2)" (按钮高亮)，半径为 1
- 操作: 在圆形揭示的 Hidden 区域 (角落) 点击单个格子
- 观察点:
  - 被点击的格子立即变为透明（Visible），绿色地形透出
  - 右侧面板统计实时更新
  - 被点击格子与相邻 Hidden 格子之间有 4px 渐变边界
- 预期: ✅ 点击即时响应 (<50ms)，单格精确更新

- 操作: 切换绘制模式为 "探索 (=1)"
- 操作: 在其他 Hidden 区域点击
- 观察点:
  - Hidden 变为半透明暗蓝灰色 (Explored)
  - Hidden↔Explored 边界处有渐变过渡
- 预期: ✅ 状态可逆，模式切换正常

- 操作: 将半径设为 3，在 Hidden 区域拖拽
- 观察点:
  - 拖拽路径上的区域即时更新（半径 3 = ~29 格圈）
  - 拖拽停止后无残留闪烁
  - FPS 保持 > 50
- 预期: ✅ 大范围拖拽流畅，无卡顿或掉帧

### 5. 步骤四: 边缘混合详细检查

- 操作: 点击 "圆形揭示" 预设
- 操作: 使用滚轮将摄像机缩放到近距离 (约 0.5x zoom)，使单个 Cell 清晰可见
- 观察点:
  - Hidden↔Explored 边界: 可见 4px 渐变条带 (从 `rgba(0,0,0,1)` 到 `rgba(18,20,32,0.55)`)
  - Explored↔Visible 边界: 可见 4px 渐变条带 (从 `rgba(18,20,32,0.55)` 到 `rgba(0,0,0,0)`)
  - Hidden↔Visible 直接边界 (如果有): 可见 4px 渐变条带 (从 `rgba(0,0,0,1)` 到 `rgba(0,0,0,0)`)
  - 同状态 Cell 之间: **无**渐变线（边界不可见）
- 预期: ✅ 渐变条带宽度均匀 (~4px)，方向正确 (水平/垂直)，无缺失或偏移

### 6. 步骤五: 3D 空间定位验证

- 操作: 旋转摄像机到不同角度（鼠标左键拖拽旋转）
  - 正上方俯视 (天顶角 < 10 度)
  - 斜 45 度视角 (默认)
  - 近乎水平的低角度 (天顶角 > 75 度)
- 观察点:
  - 覆盖层始终紧贴绿色地形表面
  - 无 Z-fighting（覆盖层与地形之间无闪烁条纹）
  - 覆盖层与地形之间的 0.005 单位间距在任何角度都不可见
- 预期: ✅ 覆盖层在所有视角下正确贴附地形

### 7. 步骤六: 悬停检查器验证

- 操作: 将鼠标悬停在不同状态的 Cell 上方
- 观察点:
  - 左下角检查器面板显示当前 Cell 坐标 (col, row) 和状态
  - 状态显示为 "Hidden (0)" / "Explored (1)" / "Visible (2)"
  - 坐标值随鼠标移动实时变化
- 预期: ✅ 悬停信息与实际视觉状态一致

## 已知限制 (Known Limitations)

- 边缘混合使用 Canvas2D 4px `createLinearGradient` 模拟，与真实 ShroudRenderer 的 GPU 8-neighbor ShaderMaterial 效果有纹理采样精度差异（Canvas2D 为整数像素级渐变，GPU shader 为浮点纹理采样）
- 此测试页面为自包含模拟，不连接真实的 Shroud/World 数据源 — 仅验证覆盖层渲染的视觉效果
- 边界外 Cell 的渐变处理使用 CLAMP_TO_EDGE 等效行为（Canvas2D 不绘制边界外内容），与真实 ShroudRenderer 在 map border 处的行为可能存在细微差异
- 不测试 FrozenActor Flash 效果、Fog visibility trait 集成或 DetectCloaked 视觉指示器（这些属于 Phase B/C 范围）
