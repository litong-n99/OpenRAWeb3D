## 期望结果 (Expected Results)

1. **静止动画 (Idle Animation)**:
   - 身体轻微上下浮动, 模拟呼吸效果
   - 可量化指标: 身体Y轴浮动范围 ±0.05 世界单位
   - 可量化指标: 左右腿保持静止, 张开角度分别为 +0.05 rad 和 -0.05 rad (对称站姿)
   - 可量化指标: 脚部保持在地面 (Y ≈ -0.65), 脚部颜色为绿色 #33CC33

2. **行走动画 (Walking Animation)**:
   - 左腿与右腿交替摆动, 相位差 180 度 (π rad)
   - 可量化指标: 左腿角度 = sin(t * 2π) * 0.25, 右腿角度 = sin(t * 2π + π) * 0.25
   - 可量化指标: 摆动幅度 ±0.25 rad, 周期等于 cycleLength ticks
   - 可量化指标: 身体在行走时上下弹跳, 弹跳频率为腿部频率的 2 倍
   - 可量化指标: 行走时角色沿身体朝向前进, 速度 0.02 世界单位/tick

3. **转向动画 (Turning Animation)**:
   - 外侧腿摆动幅度 > 内侧腿摆动幅度
   - 可量化指标: 外侧腿振幅 ±0.35 rad, 内侧腿振幅 ±0.15 rad
   - 可量化指标: 每半周期 (cycleLength/2 ticks) 切换内外侧角色
   - 可量化指标: 身体朝向每 tick 旋转 4 WAngle (约 1.4 度)

4. **动画帧回调 (ModelAnimation Frame Callbacks)**:
   - 每 40ms (1 tick @ 25fps) 更新一次所有肢体 TransformNode
   - 可量化指标: 帧计数器 frame 从 0 递增到 cycleLength-1, 然后归零
   - 可量化指标: 肢体旋转通过 TransformNode.rotation.x 直接设置 (无骨骼动画)

5. **脚部着地检测 (Foot-Ground Contact)**:
   - 腿部摆动角度接近 0 时脚部贴地
   - 可量化指标: |sin(legAngle)| < 0.02 时脚部 emissive 颜色 = (0.3, 0.5, 0.3)
   - 可量化指标: 抬腿时脚部 emissive 颜色 = (0, 0, 0) (无自发光, 变暗)

6. **状态切换 (State Transitions)**:
   - 状态切换在 1 帧内完成
   - 可量化指标: 从 Idle 切换到 Walking 时腿部角度连续变化, 无跳变
   - 可量化指标: 帧计数器在新状态下重新从 0 开始计数

## 检验流程

### 1. 准备工作
- 打开测试页面: `http://localhost:5173/test/ch19-cnc/voxel-walker/`
- 确认环境信息栏显示 "引擎: WebGL 2.0"
- 确认页面显示绿色步行机甲模型在地面上

### 2. 步骤一: 静止动画
- 点击 "静止 (Idle)" 按钮 (默认状态)
- 观察身体轻微上下浮动 (>5 秒)
- 观察左右腿保持静止, 脚部亮绿色
- 预期: ✅ 身体浮动 ±0.05, 腿部不动

### 3. 步骤二: 行走动画
- 选择行走方向 "北 (WAngle 0)"
- 点击 "行走 (Walking)" 按钮
- 观察左腿和右腿交替前后摆动 (>10 秒)
- 观察脚部颜色交替变亮/变暗 (着地时亮, 抬腿时暗)
- 预期: ✅ 左右腿摆动相位差 180 度, 角色向北移动

### 4. 步骤三: 行走方向切换
- 分别选择东、南、西方向
- 观察角色沿对应方向移动
- 预期: ✅ 北=负Z, 东=正X, 南=正Z, 西=负X

### 5. 步骤四: 转向动画
- 点击 "转向 (Turning)" 按钮
- 观察身体绕Y轴缓慢旋转
- 观察腿部振幅交替变化 (每半周期切换大摆/小摆)
- 预期: ✅ 身体朝向持续变化, 腿部振幅不对称

### 6. 步骤五: 动画速度调整
- 调整"动画速度"滑块
- 最小值 1 tick/周期: 动画极快
- 最大值 50 tick/周期: 动画极慢
- 预期: ✅ 动画周期与滑块值成正比

### 7. 边界/异常测试
- **状态快速切换**: 快速点击 Idle → Walk → Turn → Idle
  - 预期: ✅ 每次切换在 1 帧内完成, 无视觉跳变
- **重置测试**: 点击"重置"
  - 预期: ✅ 模型回到原点, 状态归为 Idle
