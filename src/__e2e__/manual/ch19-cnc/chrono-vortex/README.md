## 检验流程

### 1. 准备工作

- 打开测试页面: `http://localhost:5173/test/ch19-cnc/chrono-vortex/`
- 确认环境信息栏显示 "引擎: WebGL 2.0"
- 设置屏幕分辨率为 1920x1080 (1x 缩放)
- 确认页面显示一座建造场模型 (方块主体 + 吊臂 + 中央红点)
- 确认蓝色轨道圆形参考线可见

### 2. 步骤一: 默认参数 (3 loops)

- 操作: 点击 "启动涡旋特效" 按钮
- 观察点:
  - 涡旋粒子出现在建造场附近 (轨道上的蓝色球体)
  - 粒子沿圆形轨道逆时针旋转 (从上方俯视, WAngle 角度递增)
  - 状态栏 "阶段" 显示: OPENING → LOOP → CLOSING → COMPLETE
  - 蓝色轨迹线 (trail) 显示涡旋经过的路径
- 预期: ✅ 涡旋绕建造场旋转约 3.2 秒 (80 帧), 三个阶段正确过渡

### 3. 步骤二: 不同循环次数

- 操作: 选择循环次数 "1 次", 点击 "启动涡旋特效"
- 观察点:
  - Opening (0-15) → Loop 1 次 (16-31) → Closing (32-47)
  - 总持续时间约 1.92 秒 (48 帧)
- 操作: 选择 "5 次", 点击 "启动"
- 观察点:
  - Loop 阶段重复 5 次
  - 总持续时间约 4.48 秒 (112 帧)
- 预期: ✅ loops 参数正确控制 Loop 阶段重复次数

### 4. 步骤三: 0 次循环 (跳过 Loop)

- 操作: 选择循环次数 "0 次 (跳过Loop)", 点击 "启动"
- 观察点:
  - 阶段直接从 OPENING (0-15) 跳到 CLOSING (16-31)
  - 总帧数 = 32, 约 1.28 秒
  - 循环阶段被完全跳过
- 预期: ✅ loops=0 时涡旋直接关闭，无 Loop 阶段

### 5. 步骤四: 角度步长调整

- 操作: 调整 "每步角度" 滑块到最大值 120, 点击 "启动"
- 观察点:
  - 涡旋旋转速度明显加快
  - 角度每帧递增 120 WAngle (而非默认 42)
  - 完整一圈 (1024 / 120 ≈ 8.5 帧)
- 操作: 调整到最小值 5, 点击 "启动"
- 观察点:
  - 涡旋旋转非常缓慢
  - 完整一圈需约 205 帧
- 预期: ✅ 角度步长正确影响旋转速度
