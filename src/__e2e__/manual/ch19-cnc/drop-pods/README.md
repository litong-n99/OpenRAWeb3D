## 期望结果 (Expected Results)

1. **舱体下降 (Pod Descent)**:
   - 胶囊形舱体从天空 Y=6.0 下降到地面 Y=0
   - 可量化指标: 正常速度 0.25 单位/tick, 需 24 ticks (960ms @ 25fps)
   - 可量化指标: 快速模式 1.0 单位/tick, 需 6 ticks (240ms)
   - 可量化指标: 慢速模式 0.1 单位/tick, 需 60 ticks (2400ms)
   - 可量化指标: 舱体尺寸: 高 0.8, 半径 0.2 (胶囊形状)

2. **粒子尾迹 (Particle Trail)**:
   - 舱体下降时有橙色 #FF8800 大气再入粒子
   - 可量化指标: 粒子 emitRate=40/s, 生命周期 0.1-0.4s
   - 可量化指标: 粒子颜色渐变: 橙色 → 暗橙 → 透明 (Color1=#FF801A, Color2=#CC4D0D, ColorDead=#4D1A00)
   - 可量化指标: 舱体到达地面后粒子停止

3. **冲击效果 (Impact Effect)**:
   - 地面冲击波环从半径 0.1 扩展到 1.5
   - 可量化指标: 环扩展持续 DEPLOY_DELAY=8 ticks (320ms)
   - 可量化指标: 冲击粒子系统: 40 粒子, emitRate=60/s, 方向向上+向外
   - 可量化指标: 冲击延迟: 12 ticks (480ms) 从舱体着陆到冲击

4. **散布模式 (Scatter Pattern)**:
   - 多舱体在目标周围的圆形区域内均匀散布
   - 可量化指标: 默认散布半径 200 WDist (0.195 世界单位)
   - 可量化指标: 5 舱集群投放时每个舱体落点不同

5. **单位部署 (Unit Deployment)**:
   - 冲击后 8 ticks 出现蓝色立方体 (0.3 x 0.3 x 0.3) 代表部署单位
   - 可量化指标: 部署单位颜色 (0.2, 0.4, 0.9) — 蓝色

6. **舱体状态机 (State Machine)**:
   - DESCENDING → IMPACTING → DEPLOYED → COMPLETE
   - 可量化指标: 每个阶段转换时序正确

## 检验流程

### 1. 准备工作
- 打开测试页面: `http://localhost:5173/test/ch19-cnc/drop-pods/`
- 确认页面显示地面上的橙色目标环
- 确认环境信息栏显示 "引擎: WebGL 2.0"

### 2. 步骤一: 单舱投放
- 选择 "1 舱", 点击 "投放舱体"
- 观察一个胶囊形舱体从天空下降, 带有橙色尾迹
- 观察舱体到达地面, 约 0.5 秒后冲击波环出现
- 观察约 0.3 秒后蓝色单位出现在落点
- 预期: ✅ 完整的 DESCENDING → IMPACTING → DEPLOYED → COMPLETE 状态链

### 3. 步骤二: 集群投放
- 选择 "5 舱", 点击 "投放舱体"
- 观察 5 个舱体同时从不同位置下降
- 观察每个舱体在随机散布位置着陆
- 预期: ✅ 5 个舱体散布在目标周围, 散布半径约 0.2 单位

### 4. 步骤三: 散布半径调整
- 设置散布半径为 0, 投放 3 舱
- 观察所有舱体落到几乎同一位置
- 设置散布半径为 500, 投放 3 舱
- 观察舱体散布明显增大
- 预期: ✅ 散布半径正确影响落点分布

### 5. 步骤四: 下降速度模式
- 分别测试快速/正常/慢速
- 观察下降时间的差异
- 预期: ✅ 快速 ~240ms, 正常 ~960ms, 慢速 ~2400ms

### 6. 边界测试
- **多次投放**: 连续投放 3 次, 每次 5 舱
  - 预期: ✅ 所有舱体独立运作, 无冲突
- **重置中投放**: 投放后点击"重置", 再投放
  - 预期: ✅ 旧舱体消失, 新舱体正常
