## 期望结果 (Expected Results)

1. **光束下降 (Beam Descent)**:
   - 蓝色半透明圆柱从天空 (Y=8.0) 下降到地面 (Y=0)
   - 可量化指标: 正常速度 0.5 单位/tick, 需 16 ticks (640ms @ 25fps) 到达地面
   - 可量化指标: 快速模式 2.0 单位/tick, 仅需 4 ticks (160ms)
   - 可量化指标: 慢速模式 0.2 单位/tick, 需 40 ticks (1600ms)
   - 可量化指标: 光束顶部直径 0.4, 底部直径 0.8 (锥形光束)
   - 可量化指标: Alpha 透明度 0.6, emissive 颜色 (0.3, 0.6, 1.0)

2. **光束光照 (Point Light)**:
   - 随着光束下降, 点光源强度从 0 增加到 3.0
   - 可量化指标: 强度 = (1 - beamHeight / 8) * 3.0 (线性增长)

3. **武器冲击 (Weapon Impact)**:
   - 光束到达地面后延迟 weaponDelay ticks 触发 impact
   - 可量化指标: 默认 delay=15 ticks (600ms)
   - 可量化指标: impact 时点光源瞬间增强到 5.0 然后衰减
   - 可量化指标: impact 后 25 ticks 光束消失, isDestroyed=true

4. **地面溅射粒子 (Ground Splash Particles)**:
   - 粒子系统在 impact 时爆发
   - 可量化指标: 粒子数 60, emitRate=80/s, 生命周期 0.3-0.8s
   - 可量化指标: 粒子颜色 #4D80FF (Color1) → #99CCFF (Color2) → #1A1A4D (ColorDead)
   - 可量化指标: 粒子发射方向向上 (direction1=-0.3,1,-0.3 / direction2=0.3,2,0.3)
   - 可量化指标: 粒子持续 SPLASH_DURATION=20 ticks 后停止

5. **目标标记 (Target Marker)**:
   - 红色双环标记地面目标位置
   - 可量化指标: 外环直径 1.2, 内环直径 0.4, 颜色 #E6331A
   - 可量化指标: 标记位置固定在 (2, 0, -1)

## 检验流程

### 1. 准备工作
- 打开测试页面: `http://localhost:5173/test/ch19-cnc/ion-cannon/`
- 确认页面显示地面上的红色目标标记环
- 确认环境信息栏显示 "引擎: WebGL 2.0"

### 2. 步骤一: 默认发射
- 点击 "发射离子炮" 按钮
- 观察蓝色锥形光束从天空下降到目标位置
- 观察光束到达地面后 15 ticks (约 600ms) 地面粒子爆发
- 观察蓝色粒子向上溅射
- 观察光束消失, 粒子逐渐消散
- 预期: ✅ 光束下降 640ms, 然后延迟 600ms 后冲击, 粒子溅射

### 3. 步骤二: 速度模式
- 分别选择 "快速" / "正常" / "慢速"
- 点击"发射离子炮"
- 观察光束下降速度差异
- 预期: ✅ 快速 ~160ms, 正常 ~640ms, 慢速 ~1600ms

### 4. 步骤三: 武器延迟
- 调整延迟为 5 ticks
- 发射, 观察冲击几乎立即发生
- 调整延迟为 30 ticks
- 发射, 观察光束在地面停留约 1.2 秒后才冲击
- 预期: ✅ 延迟时间与设定值成正比

### 5. 步骤四: 三次连射
- 点击 "三次连射" 按钮
- 观察每隔 2 秒发射一次离子炮
- 预期: ✅ 三次独立的下降-冲击-粒子循环

### 6. 步骤五: 重置
- 发射过程中点击"重置"
- 观察光束和粒子立即消失
- 预期: ✅ 状态清除干净
