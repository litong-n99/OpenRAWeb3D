## B. 期望结果

### 期望 1: 线段几何正确

**观察点**: 左上角区域的水平线、对角线、竖线、横线。
- 水平线：无锯齿断裂，线宽均匀
- 对角线：45° 线平滑无锯齿
- 竖线：垂直，线宽一致
- 不同颜色的线段（红、黄、青）颜色准确

**容差**: 线宽偏差 < 0.5px，颜色肉眼与色板匹配。

### 期望 2: 矩形边框闭合无缺口

**观察点**: 中上矩形边框。
- 四角闭合完整，无缺口或错位
- 角点无凸出或重叠

### 期望 3: 填充矩形颜色均匀

**观察点**: 右上填充矩形。
- 填充色均匀，无渐变条带
- 边框半透明叠加可见

### 期望 4: 椭圆填充近似正确

**什么是扫描线**：扫描线法是用多条水平细矩形逐行填充椭圆，类似于
显示器逐行扫描的原理。由于用水平矩形逼近曲线边缘，边界天然有阶梯感
（stair-step），这是扫描线法的固有特征，并非 bug。本测试约 40 条扫描线
（步长 0.05-0.09），阶梯感已大幅减小。

**观察点**: 中部两个椭圆（一个扁、一个高，世界坐标：大椭圆 rx=1.2 ry=1.8，
小椭圆 rx=0.6 ry=1.5）。
- 椭圆形状对称，左右镜像无畸变
- 扫描线之间无可见空隙（相邻矩形接缝处不透背景光）
- 边界呈均匀阶梯状（stair-step）接近椭圆外形，无突变跳点或异常凸起
- 两个椭圆均接近其真实的椭圆轮廓，肉眼无可见变形

### 期望 5: 五角星多边形正确

**观察点**: 左下五角星。
- 五个尖角清晰可辨
- 填充无空洞
