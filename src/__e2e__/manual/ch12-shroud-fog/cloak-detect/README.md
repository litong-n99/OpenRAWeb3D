## 期望结果 (Expected Results)

1. **探测范围外不可见**: 当探测器距离隐形单位大于探测范围时，隐形单位保持不可见。
   - 可量化指标: 探测器初始位置 X=-3.0, Z=0，距离为 3.0 单位；探测范围默认 2.0 → 隐形单位不可见
   - 可量化指标: `detectionCircle` 半透明蓝色圆形不覆盖红色步兵位置

2. **探测范围内完全可见**: 当探测器移动到探测范围内时，隐形单位变为完全可见。
   - 可量化指标: 将探测器 X 滑杆移动到 -2.0 时（距离=2.0），隐形单位 alpha=1.0 完全可见
   - 可量化指标: 状态面板显示 "DETECTED (范围内=true, 类型匹配=true)"

3. **离开范围后恢复不可见**: 探测器移出范围后隐形单位立即恢复不可见。
   - 可量化指标: 将探测器 X 滑杆移回 -3.0 时，隐形单位立即消失
   - 可量化指标: 无延迟或残留渲染

4. **DetectionTypes 过滤**: 只有匹配的 DetectionTypes 才能揭示隐形。
   - 可量化指标: 将 DetectionTypes 下拉菜单切换到 "Subterranean" 后，即使探测器在范围内（距离≤2.0）隐形单位仍然不可见
   - 可量化指标: 状态面板显示 "Not Detected (范围内但类型不匹配)"
   - 可量化指标: 切换回 "Cloak" → 隐形立即解除；切换到 "None (不匹配)" → 隐形势在，距离 0 时也不可见

5. **探测圈可视化**: 探测器周围显示半透明蓝色圆盘表示探测范围。
   - 可量化指标: 圆盘半径随范围滑块变化（1.0 ~ 4.0），alpha=0.2 半透明
   - 可量化指标: 圆盘中心随探测器位置变化

## 检验流程

### 1. 准备工作

- 打开测试页面: `http://localhost:5173/test/shroud/cloak-detect/`
- 确认: 红色步兵在原点 (0,0)，蓝色探测器在 (-3, 0)，周围有蓝色探测圆圈
- 确认环境信息栏显示 **"引擎: WebGL 2.0"**

### 2. 步骤一: 范围外不可见

- 操作: 页面加载后默认探测器在 X=-3.0（距离=3.0），探测范围=2.0
- 观察点:
  - 红色步兵不可见（仅绿色棋盘格地面可见）
  - 蓝色探测圆圈覆盖 X∈[-5,-1] 范围，不覆盖原点
- 预期: 状态面板显示 "Not Detected (距离超出范围: 3.00 > 2.0)"

### 3. 步骤二: 进入范围后可见

- 操作: 拖动"探测器位置" X 滑杆从 -3.0 向右到 0
- 观察点:
  - X=-2.0（距离=2.0）时: 红色步兵开始可见
  - X=0（距离=0）时: 红色步兵在探测器正下方，完全可见
  - 蓝色探测圆圈覆盖原点
- 预期: 状态面板从 "Not Detected" 变为 "DETECTED"

### 4. 步骤三: 离开范围后恢复不可见

- 操作: 将 X 滑杆拖回 -3.0
- 观察点:
  - 红色步兵立即消失
  - 无延迟、无闪烁
- 预期: 状态面板恢复 "Not Detected"

### 5. 步骤四: DetectionTypes 过滤

- 操作: 将探测器 X 移回 0（红外兵在范围内）
- 观察点: 红色步兵可见
- 操作: 将 DetectionTypes 下拉菜单改为 "Subterranean"
- 观察点:
  - 红色步兵立即消失（类型不匹配）
  - 状态面板: "Not Detected (范围内但类型不匹配)"
- 操作: 将 DetectionTypes 改为 "Both" (Cloak+Subterranean)
- 观察点: 红色步兵再次可见
- 操作: 将 DetectionTypes 改为 "None (不匹配)"
- 观察点: 红色步兵始终不可见，即使距离=0
- 预期: DetectionTypes 过滤在所有距离上都正确工作

### 6. 步骤五: 探测范围调整

- 操作: 将 DetectionTypes 改回 "Cloak"
- 操作: 将探测器 X=0，探测范围从 2.0 逐步减小到 1.0
- 观察点:
  - 范围=2.0: 蓝色圆圈半径大，覆盖大量区域
  - 范围=1.0: 蓝色圆圈半径缩小
  - 距离=0 时始终可见（因距离≤范围）
- 操作: 将探测器 X=-1.5（距离=1.5），范围调为 1.0
- 观察点: 距离 1.5 > 范围 1.0 → 不可见
- 操作: 将范围调回 2.0
- 观察点: 距离 1.5 ≤ 范围 2.0 → 可见
- 预期: 范围变化即时生效，圆圈半径同步更新

### 7. 边界/异常测试

- **边界 A - 双轴移动**: 同时拖动 X 和 Z 滑杆
  - 预期: 距离计算使用欧几里得距离 sqrt(dx^2 + dz^2)，验证对角距离（如 X=1.5, Z=1.5，距离=2.12 > 2.0 → 不可见）
- **边界 B - 范围边界精确**: 将探测器放在距离刚好等于范围的位置
  - 预期: 距离≤范围判定为可见（边界包含）
